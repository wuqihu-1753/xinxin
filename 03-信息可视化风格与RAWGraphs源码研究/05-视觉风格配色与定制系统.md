# 05｜RAWGraphs 视觉风格、配色与可定制参数

> **阅读边界**：源仓库中 UI 的 Sass 主题与输出图表的视觉参数是**不同的系统**。前者有明确颜色/字号的静态样式；后者多数参数由各 chart 包的 `visualOptions` 配置而非在 app 源代码中逐图写死。
>
> 代码：[src/styles/index.scss](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/styles/index.scss)、[src/components/ChartOptions/ChartOptions.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/components/ChartOptions/ChartOptions.js)、[src/components/ChartOptions/ChartOptionTypes/ChartOptionColorScale.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/components/ChartOptions/ChartOptionTypes/ChartOptionColorScale.js)。

## A｜源码中真正存在的“风格层”

1. **界面主题样式（SRC）**：`src/styles/index.scss` 的 Sass 变量将 UI 主色设为 `#4bc06a`、页面背景 `#f5f8fa`；正文使用 Inter 字体栈，等宽字体栈为 IBM Plex Mono；相关 CSS 变量也包含灰阶与 header 高度。这些是**操作界面的色彩和字体**，不是每张输出图的默认配色。
2. **图形自定义控制（SRC）**：ChartOptions 根据 Core 返回的 `getOptionsConfig`，渲染 number、text、color、colorScale、boolean 五类控件；部分数字型选项可能采用下拉式 select；支持条件启用和对多字段映射重复的选项。
3. **颜色尺度（SRC）**：ChartOptionColorScale 使用 Core 的 `getAvailableScaleTypes`、`getColorDomain`、`getInitialScaleValues`、`getColorScale`、`colorPresets`。app 定义标签 `sequential`（顺序）、`diverging`（发散）、`ordinal`（分类）。能看到 reset、invert、lock（重置/反转/锁定）控件，和未映射数据时的 defaultColor。
4. **尺寸与图例（SRC）**：ChartOptions 在界面说明 `containerOptions.width/height` 包含 legend；不同图的实际控制项取决于 chart 配置，不能说所有图都支持完全相同的 padding、标签、轴和图例。
5. **SVG 二次设计（SRC＋DESIGN）**：Exporter 支持直接输出 SVG；将其导入矢量编辑器后可继续设置版式、标题、图例、注释和主题插画。**二次设计需要保留数值映射，不应为美观更改比例几何。**

## B｜点、线、面、体、符号、色彩的设计审读

| 维度 | RAWGraphs可建立的机制（依图表而异） | 推荐记录 | 典型误区 |
|---|---|---|---|
| 点 | 散点、蜂群、气泡、节点位置 | 坐标轴、点形/半径映射、重叠处理 | 把抖动横移当第二个数值变量 |
| 线 | 折线、名次线、树枝、弧线、流带边界 | 连接关系、宽度/方向、来源与目标 | 把“视觉连接”误判为因果或数量流 |
| 面 | 树图、圆图、矩阵色格、面积图 | 面积是否∝值；分母和类别边界 | 半径线性编码导致面积平方夸大 |
| 体 | App内主要是 SVG 2D 图形；立体主题由设计者后期处理 | 是否透视、是否编码体积 | 凭真实感装饰推断统计数值 |
| 符号 | 图表节点、类别标记、图例符号 | 类别图例与重复单位 | 把每个象形符号默认看作相同数量 |
| 色彩 | 分类、顺序、发散、默认/缺失色 | 分类字典、数值域、色盘版本 | 跨模块同色被误当为同一统计变量 |

## C｜从现有 UI 参数导出的“设计风格方向”（DESIGN，不是官方预设）

| 风格方向 | 视觉策略 | 推荐主图机制 | 需要补充的信息 |
|---|---|---|---|
| **理性统计/科研风** | 黑灰文字、有限强调色、共同基线、清晰单位 | 条形、折线、箱线、矩阵、点图 | 轴与单位、置信区间、数据出处 |
| **编辑信息图风** | 主图SVG＋大标题＋阅读分区＋解释卡片 | 流图、树图、桑基、Gantt、矩阵组合 | 标题、事实/推断、主次叙事 |
| **层级有机风** | 径向层级、大小嵌套、类别色族 | Circle Packing、Sunburst、Voronoi Treemap | 父子关系、加总逻辑、面积图例 |
| **关系网络风** | 少色相、合理透明度、局部高亮、可追踪连接 | Chord、Arc、Alluvial、Sankey、Matrix | source/target/weight定义，方向与密度 |
| **时间叙事风** | 单向标尺、事件注释、持续时段与关键转折 | Line、Gantt、Bump、Streamgraph、Calendar | 时区/时间间隔、日期精度、序列区分 |
| **抽象几何风** | Voronoi、Hexbin、Contour、Convex Hull 的形态语言 | 几何密度/空间剖分 | 几何面积/位置是否真正源自数据 |
| **高信息密度目录风** | 小倍数、统一单元模板、矩阵、稳定字级 | Matrix、Treemap、Radarchart（视任务） | 条目收录规则、字段一致性和局部图例 |

**注意**：“编辑风、层级有机风”等是为 xinxin 建立的可视化风格研究标签，**RAWGraphs 当前源码未提供一键切换的上述命名风格模式**。

## D｜配色尺度的正确选择（DESIGN）

- **ordinal**：无天然大小关系的类别用离散色；例：职业、品种、地区类别。
- **sequential**：从低到高的非负或同一方向数值域，用顺序色；例如人口或平均工资。
- **diverging**：具有明确中心值（如0、平均、目标线）的正负偏差，用发散色；需要写明中心是什么。
- **缺失/无效**：不应随意染成“最小值”的颜色；提供单独标签/纹理或缺失说明。
- **图内一致 vs 跨图一致**：两张图中的同一个类别有可能需要稳定颜色，但同一个红色不能在“涨跌”和“预测类别”中无标注混用。

## E｜SVG二次编辑的准确性规范

1. 固定原图的 **数据版本、字段映射、聚合规则和数值域**；
2. 输出 SVG，并在矢量软件中分组为“坐标/数据图元/文字/图例/注解”；
3. 可以改变字体、字号、排版密度与辅助图标，但**不要随手拉伸单根数据柱、气泡或流带**；
4. 若需要专题封面或插画叙事，用独立插画层叠加；原数据图形保留可复算路径；
5. 记录主题视觉规则和修改说明，便于未来案例增量更新。
