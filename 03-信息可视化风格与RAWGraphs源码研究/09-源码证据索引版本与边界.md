## C. 十项需要明确保留的研究边界

1. **未克隆或运行完整 npm 项目**：分析基于 GitHub 固定提交的文件阅读和示例表头，未测具体浏览器表现。
2. **未读完所有 rawgraphs-charts 图的布局实现**：图内具体数学公式须另外审阅图表库，app 只管理其注册与调用。
3. **32 是本提交的注册数量**，不是全球所有 RAWGraphs 扩展图表数量或当前线上必然可用的总图数。
4. **27是 public/sample-datasets 下文件数**，并不意味着与32图一一对应。
5. **前端 style.scss 中的绿灰主题属于 UI**，不可当成图表导出配色。
6. **软件许可 ≠ 样例数据和第三方图像的任意使用许可**，逐例检查 sample 来源。
7. **“在浏览器处理”不等于“无外部请求”**，源码包含 URL/SPARQL fetch 和 GA script。
8. **自定义 JS 的确认弹窗不等于沙盒**，存在执行不可信代码的风险。
9. **SVG文件可编辑不等于保留计算/数据绑定**，精确复算要保存数据和 .rawgraphs。
10. **设计风格分类（理性、编辑、径向、几何等）是 xinxin 研究框架**，不冒充 RAWGraphs 官方预设。

## D. 可扩展研究优先级（本次未越界）

1. 以 [rawgraphs-charts](https://github.com/rawgraphs/rawgraphs-charts) 的单图 `metadata/dimensions/visualOptions/viz` 源码，逐项补完32图精确字段要求、算法和样式范围。
2. 以 rawgraphs-core 的源实现补完 aggregation、parseDataset、颜色尺度域与项目schema。
3. 将 08 的八组样本真正加载浏览器，导出SVG/项目，生成可追溯的视觉截图和参数文件。
4. 在有版权和数据许可时，再进入 02 的新增视觉案例图；01中只保留链接和概念更新。

**研究状态**：固定版本的代码结构和部分样本字段已核验；内置图图形算法、性能以及部署线上版本一致性不在本次已验证范围。
