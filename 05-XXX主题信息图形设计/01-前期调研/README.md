# 阶段01｜前期调研

**目的**：决定为什么做、给谁看、要回答什么，而不是先选海报风格。

## 输入 → 操作 → 输出
- **输入**：XXX选题设想、初始关键词、目标媒介或课程要求、时间预算。
- **操作**：查学术/官方/行业背景，梳理历史与现状；识别目标受众的知识水平、认知难点与阅读环境；调查至少若干具有不同策略的设计案例（不限定固定数量）。
- **输出**：[前期调研卡](选题调研与问题定义模板.md)、参考作品链接、数据可得性风险。
- **通过条件**：一句话问题能被回答；明确读者是谁、需要的证据是什么；记录了来源及空白点。

## 调研方面
1. 主题边界：时间、地点、对象、核心概念及不研究什么。
2. 价值：读者为什么需要这份信息图，它解决比较、解释、查找还是决策问题？
3. 文献/政策/背景：优先原始与权威公开来源，保留版本时间。
4. 同类案例：主视觉、信息架构、数据图形、文字层级、来源和可验证性；不可简单照抄参考图。
5. 约束：数据是否可得、授权、隐私、印刷尺寸/设备、受众可读性。
6. 提炼：提出三个以内候选叙事命题，记录反例与未解决疑问。
