# 阶段03｜数据搜集

**三种来源分别存放**：官方/公共开放数据集、文本文献、自建数据集。任何资料进入基础数据表前，都必须记录**来源、口径、时间、许可、抽取或整理方法**。

| 子目录 | 适合内容 | 典型风险 |
|---|---|---|
| [01-公共数据集](01-公共数据集/README.md) | 统计网站CSV/JSON、开放地理数据、公开研究数据集 | 时间口径、数据版本、许可 |
| [02-文本文献](02-文本文献/README.md) | 论文、年鉴、图书、报告、政策、档案、可引用段落 | 断章取义、页码、OCR错误、二手转引 |
| [03-自建数据集](03-自建数据集/README.md) | 问卷、实地观察、标注、摄影归档、人工编码 | 采样偏差、知情同意、个人信息 |

使用 [来源台账模板](来源台账模板.csv) 为每项资料分配 SRC-编号；原始内容不直接覆盖，所有裁剪/转换需留清洗记录。

**注意**：此文件夹当前仅含结构模板，**不包含已验证的XXX项目公共数据**。第三方大型原始文件、版权不明照片及敏感记录不应直接推送到公开GitHub。

阶段完成检查：来源能追溯、关键字段定义可读、授权可用、至少可以支持核心叙事模块的一部分；不能获得的数据必须说明缺口，不能使用模型虚构填补。
