# CASE-0054｜数据字典

[基础数据集](./基础数据集.csv)有 **17 行、11 列**。每行记录一个可辨文字、栏目、入口类型或关联条目，取自 `Visual Resume简历2.png`。条目为图面信息，履历背后的个人事实尚未独立核验。

| 字段 | 定义 |
|---|---|
| `record_id` | 公开案例内的稳定记录标识 |
| `module` | 图示栏目或归纳模块 |
| `label` | 可辨标签或去识别后的图面描述 |
| `record_role` | 履历、项目、成果、能力标签、工具、模块、步骤或入口类型等 |
| `start_on_image` | 版面提供的起点或单年，保持图面精度 |
| `end_on_image` | 版面提供的终点或继续状态；无对应信息时留空 |
| `method_step_order` | 设计方法内部的步骤序号；其他记录留空 |
| `related_id` | 同一项目对应的原条目ID；无明确关联时留空 |
| `employment_type` | 版面明示的用工性质，其他条目留空 |
| `source_id` | 本次用户样图标识 |
| `evidence` | E1为图上可辨的栏目、词项、年份或位置 |

竞赛条目及两条成果说明统一用 P02 作为项目索引，作品入口按类型转录。
