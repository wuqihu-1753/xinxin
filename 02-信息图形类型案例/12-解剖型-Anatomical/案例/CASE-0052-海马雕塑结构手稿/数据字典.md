# CASE-0052｜数据字典

[基础数据集](./基础数据集.csv)有 **10 行、6 列**。一行是一项图面构件与体节索引，均来自用户提供的 `image(20261127-114250).png`。

| 字段 | 定义 |
|---|---|
| `record_id` | 图面索引记录标识 |
| `label_on_image` | 可辨认的标签或区间标题 |
| `label_type` | 字母索引、体节编号或体节总表 |
| `display_area` | 标注在手稿中的位置，用于检索 |
| `source_id` | 用户截图标识 |
| `evidence` | E1表示标签或标题可辨 |

字母与数字保留为检索标签。体节总表的范围按图示引文转录，不能替代每节详细说明。数值尺寸、角度与手写材料备注因缺少清楚的单位或基准暂未录入。
