# CASE-0051｜数据字典

[基础数据集](./基础数据集.csv)有 **12 行、7 列**。一行是一项图面部件与控件标签，均来自用户提供的 `解剖2.png`。

| 字段 | 定义 |
|---|---|
| `record_id` | 图面标签标识 |
| `label_on_image` | 可辨原文，跨行合并 |
| `zh_label` | 供检索的中文名称 |
| `label_group` | 本案按图面位置归纳的说明组 |
| `number_on_image` | 图面编号，未编号留空 |
| `source_id` | 用户截图标识 |
| `evidence` | E1为可读标签或编号 |

标签组用于查阅。主图是结构与成像示意；编号只记录图面说明入口，不是装配工序。光圈、快门、ISO及白平衡指标需各自保留量纲，未在本表合并为一类数值。
