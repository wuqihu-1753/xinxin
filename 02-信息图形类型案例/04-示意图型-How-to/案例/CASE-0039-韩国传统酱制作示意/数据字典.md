# CASE-0039｜基础数据集字段字典

[基础数据集](./基础数据集.csv)有 **7 条图面记录、6 列**。来源为用户提供的 `示意图3.png`（774 × 1080 px）。一行对应一个可辨识的中央工序或产物。两种成品共享同一前驱；行顺序不表示分支之间有前后。

| 字段 | 类型 | 定义 |
|---|---|---|
| `node_id` | 字符串 | 中央主图节点唯一标识 |
| `label_on_image` | 字符串 | 图面可读英文标签的转录，保留字词 |
| `node_type` | 字符串 | 工序或产物 |
| `predecessor_id` | 字符串 | 沿图示路径的上一个已选录节点；起点留空，中间小图可省略 |
| `visual_cue` | 字符串 | 画面上用于定位节点的可见线索 |
| `evidence_status` | 字符串 | E1＝截图直接可见 |

本表用于复核图面标记和组织关系。月份、时长和用量未录入；旁栏内容与制作主线分别阅读。
