# CASE-0038｜基础数据集字段字典

[基础数据集](./基础数据集.csv)有 **7 条图面记录、6 列**。来源为用户提供的 `示意图型.png`（600 × 981 px）。一行对应一项图面观察。无可读标签时留空。

| 字段 | 类型 | 定义 |
|---|---|---|
| `observation_id` | 字符串 | 图面观察记录唯一标识 |
| `label_on_image` | 字符串 | 图面可读标签；画面未给标题的图元留空 |
| `observation_type` | 字符串 | 根对象、部件标注、机制标注或场景图元 |
| `subject_id` | 字符串 | 标注或图元在版面上所关联的整体对象；检索关联，不自动等同于部件归属 |
| `visual_cue` | 字符串 | 画面上用于定位该记录的可见线索 |
| `evidence_status` | 字符串 | E1＝截图直接可见 |

本表用于复核图面标记和组织关系。部件实际尺寸、分子数量及作用参数未录入。
