# 02｜文字型／列表型信息图形（Informational / List Infographics）

> **版本 v0.6｜课件核验＋两张独立作品的反向分析**。已以课件示例作初步视觉核验。

## 1. 工作定义和边界

以标题、关键数字、简短文案、清单条目、序号、图标卡片等作为主要信息承载结构，通过层级排版和重复视觉单元提高扫描效率。**文字型**偏向阐释概念与知识，**列表型**偏向多条目罗列、步骤、提示或对照；二者可以重叠。

它们是**表现形式**，不等于 01 的编目型数据逻辑：同一列表可能承载编年步骤、分类知识、A–Z索引，也可能是非数据的建议清单。

## 2. A｜底层数据逻辑

典型字段：item_id、heading、body、item_order、category、icon、evidence、source；数字排序、优先级排序、分类排序、字母排序均需声明规则。列表若含“第1步→第2步”可带依赖关系；如果只是“10个建议”，并不当然存在层级或因果。

## 3. B｜统计图形与计算

文字说明可完全不涉及统计；有数值时可配迷你条形、比例符号、数值卡、进度条、简单表格。辨认“10项内容”的编号10与“统计量10”的不同。涉及百分比需分母，涉及排序需明确指标和方向。

## 4. C｜视觉编码

- **点**：项目圆点/定位标签；大小变化通常不代表数值。
- **线**：项目分隔、步骤引导和章节分区；箭头仅用于真实顺序/流程。
- **面**：等宽卡片与栅格建立并列关系，异形底框突出重点但需限制数量。
- **体**：没有数据编码需求时不采用三维体积暗示重要性。
- **符号**：每条目匹配语义明确的单色图标，Isotype风格图形要遵守同一笔画与造型规则。
- **色彩**：类别色、状态色、重点色有清晰职责；同级标题色彩保持一致。
- **字形与层级**：主标题→分组→项目标题→正文→出处；字号、字重、间距和编号机制共同确定阅读顺序。

## 5. D｜数据/信息架构

标题/问题 → 简明导语 → 分组 → 标准化条目模板 → 延展解释/例外 → 来源。长列表需要目录、索引或分组；单屏必须支持快速扫描和按需深读。

## 6. E｜视觉叙事架构

问题导入 → 概括性要点 → 分组展开 → 典型条目突出 → 可执行结论或综合对照。列表不要求所有条目连续讲故事，也可为非线性查阅服务。

## 7. 逐图观察清单

记录标题占比、项目数、分组方法、文字密度、编号机制、符号功能、空白比例和信息获取路径。特别检查：等大小卡片是否因异常强调而误导重要性；“排名”有没有可核验的依据。

### 10.1 A｜底层信息结构新增两种可复用模板

1. **中心人物＋分组查阅型**：`topic → {section_id, person_id, title, body, icon/image, supporting_metric?} → {detail_row, columns}`。人物与专题卡为可复用并列记录，表格为更深一级的检索信息。**并列不等于排序或父子关系。**
2. **时间阶段＋嵌套列表型**：`{era_id, century, narrative_heading} → [{keyword, item_type, explanation, example_source}]`。纵向时间有序，单阶段内部是可独立浏览的商品／社会现象／品牌／理念列表。**时间顺序与列表顺序是两种不同的秩序**，不能用一种排序字段覆盖另一种。

新增**最小表字段建议**：`topic_id, module_id, item_id, item_type, display_order, order_basis, primary_relation, evidence_level, source`；有明确时间时增加 `era_id, start/end`，有定量小图时增加 `metric, value, unit, denominator, metric_source`。例如“16th century”是阶段键，“ROYALTY”是类别名词，“pie slice”需额外数值字段才能称统计测量。

### 10.2 B｜统计与非统计的边界：数字、图框、短词不自动成为图表

- **CASE-0034**：饼形/条形局部统计的图形原型可见，数值分母与图例不可清楚辨识。允许分类为**局部统计辅助**，禁止声称已验证成员贡献、歌曲销量、精确比率。
- **CASE-0035**：世纪数字、物品清单、蓝框、折线导航都属于**信息结构编码**，无可直接计算的连续量；页面上没有“消费额—世纪”的定量折线。
- 条目**个数**和显示**序号**可以是编排属性，**排名**必须另有排序指标，**统计频数**必须另有总体和计数规则。
- 对文本信息图的评价优先问：“能否准确发现某条目、辨认分组、找到出处？”而非强行要求每页有折线图/百分比。

### 10.3 C｜点、线、面、体、符号、色彩、文字的具体编码约束

| 元素 | 从两例归纳的可行做法 | 易出现的误判 |
|---|---|---|
| 点 | 人物索引点、时期节点用于定位信息 | 未声明数量单位时，不把点数当频率 |
| 线 | 分隔线、表格行列线、世纪导航线服务检索/路径 | 导航折线≠数值曲线；连接≠因果 |
| 面 | 大肖像或实例图片作主题锚；色块/边框划分可阅读单元 | 图片面积与背景色块面积不自动编码重要性/数量 |
| 体 | 摄影明暗、历史器物质感提升辨识度 | 立体感不是数据体积 |
| 符号 | 人物、乐队文化符号、历史消费物件与对应条目作语义配对 | 主题图像不等于有“1图＝N人”的 Isotype 统计 |
| 色彩 | **暖底色+少量强调**（人物编目）或**蓝线框+粉色实例**（世纪清单）建立两种导览体系 | 不要因两块颜色不同就虚构不同统计等级 |
| 文字 | **总标题→类目/世纪→条目名→小注→来源**；保持平级条目相同字重和间距 | 重要性/时间/类别的字号差异需要语义解释，避免“大字＝多”的误读 |

### 10.4 D｜信息架构：三层访问与双轨导航

- **“先识别、再扫描、后深读”三层访问**：顶层主标题＋主图／中心概念，中层并列模块标题及关键词清单，底层详述、数字图例、表格、出处。三层文字各有任务，不能因视觉拥挤就删去单位与来源。
- **非线性并列检索（CASE-0034）**：读者可以从任何一位成员开始，并跳到底部资料表；仅把四位成员上下排版不等于形成历史顺序。
- **线性时间主线＋非线性清单支线（CASE-0035）**：读者沿 16—21 世纪前进，但同一世纪内的清单无需按严格发生顺序阅读。
- **用内容决定主次，而非装饰形式**：先问主要信息是否依赖时间、类别、层级或空间，再标“列表型”这种视觉呈现方式；这正是本仓库 01/02 双轴分类。

### 10.5 E｜新增两类视觉叙事原型

1. **百科式人物主题**：`主题提出→核心人物识别→多条平级人物介绍→局部图形/文化物件→高密度资料检索`（CASE-0034）。结论不要求强制单线闭环。
2. **阶段论证式主题**：`概念界定→分段时间推进→每阶段列证→现代转折→开放性未来提问`（CASE-0035）。**先后不自动证明因果**；“消费趋向非炫耀”的说法应表述为图中设计论点。

### 10.6 决策检验清单与证据边界

1. 删除列表文案，仅保留图片/蓝框，还能否准确传达关键知识？若不能，则以**文字/列表**作主表现。
2. 删除时间排序后意义是否大幅破坏？若是，**01主逻辑为编年**；否则可能是编目。
3. 有几条互不依赖的条目？是**平级目录、依序步骤、历史事件、还是排名**？必须分别标注。
4. 所谓“统计图”是否拥有指标、可辨量纲、分母或数值来源？没有则保留 **E0**，不臆造计算。
5. 连接线表示**导览、时间、部件标注、依赖、因果还是数值趋势**？要依据图例/语境判断。
6. 读者可以**跳读**还是必须依**固定顺序**阅读？可同时出现主线/支线。
7. 视觉作品的原作者、首次发表、史实资料与版权必须分别核查；校方网页可以认证作品背景，不能自动认证全部历史论断。

## 11｜类型深化：内部结构、原子字段与读图验证（2026-11-24）

> **范围**：在原A—E定义及[CASE-0034](案例库/CASE-0034-披头士四人组知识编目信息图.md)、[CASE-0035](案例库/CASE-0035-炫耀性消费世纪时间线信息图.md)的既有记录上增加可复用方法。这是02表现类型的深化，下面的内部模板不是新的表现类型或01数据逻辑。图中可见内容标E1，设计推断标E2，未验证的数字/史实标E0。

### 11.1 文字型和列表型的操作性定义

**文字型／列表型信息图形**：以概念、说明、关键词、标准化条目、表格等文字信息单元作为主要的可复述知识载荷，经标题层级、分组、次序、图文配对及导览完成解释、查找和对照。**文字型**偏解释“是什么、为什么”；**列表型**偏展示“有哪些、属于哪组、怎样找到”；同页可以重叠。

判定采用三个问题，而不是只数有多少段文字：（1）拿掉段落和条目，核心知识是否消失；（2）读者是在查找/解释，还是主要依赖精确数值坐标读图；（3）肖像、图标、表格、时间路径是说明配角，还是另有一个主导的量化任务。即使含饼图或时间轴，仍可能是文字列表主表现。

### 11.2 四种内部组织模板（不新增编号）

| 模板 | 信息结构 | 主要任务 | 使用界限 |
|---|---|---|---|
| 概念解释型 Informational | 概念→论点→短说明→实例/来源 | 理解知识 | 段落与证据不能被装饰性口号取代 |
| 平级条目型 List | 主题→类别→可独立查阅的清单 | 分类查找、属性比较 | 项目顺序不默认是排名 |
| 主题图文复合型 | 核心主视觉→人物/对象栏目→小图及明细表 | 主题识别＋逐项检索 | [CASE-0034](案例库/CASE-0034-披头士四人组知识编目信息图.md)；肖像面积非数值权重 |
| 分期嵌套列表型 | 时间阶段→同期关键词和案例→综合命题 | 纵向编年、组内跳读 | [CASE-0035](案例库/CASE-0035-炫耀性消费世纪时间线信息图.md)；时间序列与词项顺序不同 |

### 11.3 A／D｜基础数据集：一列一变量，一格一个原子值

以下是**重新设计案例所需的字段蓝图，不是从低分辨率图片还原出的原始数据**。多值关系拆成关联表，一行一个条目或一对关联。

| 数据表 | 原子字段（以逗号分隔的是不同列名） | 主要约束 |
|---|---|---|
| **sections 版块表** | section_id, topic_id, heading, section_type, display_order | 一个版块一行；显示顺序是编辑顺序 |
| **items 条目表** | item_id, section_id, item_label, item_type, body, display_order, source_id | 一个条目一行，区分人物/物件/社会现象/观点 |
| **eras 时期表（可选）** | era_id, century_label, era_order, date_precision, start_year, end_year | 世纪精度不可擅自伪装为具体年份 |
| **item_era 多对多关联（可选）** | item_id, era_id | 一个条目跨多个时期时用多行记录，不将多个值塞在同一格 |
| **metrics 定量指标（可选）** | metric_id, item_id, measure_name, value, unit, denominator, period, source_id | 只有获得可信数值后才填；缺失不得填0 |
| **media 媒体（可选）** | media_id, item_id, caption, media_role, creator, license_status | 区分举例图像、主题主视觉、统计象形符号 |
| **sources 来源表** | source_id, citation, url, verification_status | 作者、图像许可与历史主张分别核验 |

**关键约束**：display_order仅控制画面顺序，不等于时间、频率、优先级或rank。收录的条目数量只是编辑取样数量，不等于社会总体数据。想做排行榜须另有同口径数值指标和排序方向。图片中看不清的原始数值不得编造。

### 11.4 B／C｜编码与误读边界

| 编码通道 | 正确作用 | 常见误读 |
|---|---|---|
| 点、圆点、序号 | 识别条目和阅读位置 | 编号不自动构成排名或统计频数 |
| 线、箭头、连接 | 表格分隔、导览方向、明确的对象关系 | 连线不自动证明因果、流量、时间比例或量化走势 |
| 面、卡片、图片面积 | 建立分组、注意力和信息容器 | 底框/肖像大小不代表数量或人物贡献 |
| 图像、插画与符号 | 举例、语义匹配、文化主题识别 | 未声明每图计量单位时，不能贴已确认Isotype定量标签 |
| 色彩 | 组别一致性、导航强调、表格隔行扫读 | 交替色带不自动表示高低等级或数值类别 |
| 文字层级 | 主标题→分组/世纪→条目→解释→图例/出处 | 字号大不意味着“更多”；来源和单位不能因拥挤而删除 |

局部饼图/条图需分别记录指标、分母、单位、基线及来源，不能把“有圆形分区”视为已经核算了百分比；世纪标题是时间阶段标签，不是消费量数值。**清单≠排名，导览线≠数值折线，图文并置≠史实核实。**

### 11.5 E｜阅读与叙事：双路径判定

- **人物主题百科式（CASE-0034）**：主题→核心图像→四个平级人物栏目→局部图形解释→底部细项查阅。栏目可自由选读，换位置不改变成员事实。
- **分期推进式（CASE-0035）**：概念界定→16至21世纪阶段推进→时期内部关键词跳读→概念转折→未来问题。阶段不能任意互换，内部词条无须按历史首次出现时间排列。
- 后续逐图检查五项：主要文字载荷、条目关系和排序依据、图/线/色块真正编码的含义、指标及来源是否可核、顺序是否强制以及读者可否跳读。

### 11.6 读者验证方案（设计建议，不是已经获得的实验结果）

**定位任务**：指定人物或世纪，请读者找对应关键词，记录正确率/耗时；**归属任务**：判断条目对应哪个人物或时期，记录错配位置；**语义任务**：询问读者蓝线是否代表统计曲线、大肖像是否意味着数量最大，记录误读。做两版排版对照时保持事实内容、画布和字号基本不变，仅改变组内/组间间距、统一卡片或导览路径，记录媒介与观看距离。**没有实测则只称“设计假设”**，不得虚构阅读效率提升百分比。
