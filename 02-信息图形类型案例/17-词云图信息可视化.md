# 17｜词云图信息可视化（Word Cloud Visualization）

> **版本 v0.4｜2026-11-19**。本条为 02 的第17种**视觉表现类型**，不是新增的第六种数据逻辑。由用户同日上传的两幅黑白文字海报引出；两幅均属于**词云式实验排版的视觉参照**，目前不具有可复核的词频数据。

## 工作定义与边界

**统计词云（Word Cloud / Tag Cloud）**：把文本分词或标签列表转化为词项集合，以词频、权重等明确数据字段映射词语的视觉突出程度（常见为字号），再借助排列、方向、颜色和留白进行整体呈现。它适合快速识别高频词，但**不是精确比较数值差异的首选图表**。

**词云式文字海报／实验性字体编排（Typographic Composition）**：使用大量文字、比例差异、疏密、重复、透视和构图制造视觉效果；**没有明确的词频—字号映射证据时，不应声称统计意义**。本次两张用户图目前归入此类，并作为第17类的**边界案例**。

它与[11｜文字可视化](11-文字可视化信息图形.md)的关系：11是较宽的总类，可包含词语关系网络、文字主题图、词云；17专门讨论**词项聚合、权重映射与文字聚集布局**，并收录易混淆的艺术性排版反例。

## A｜基本数据逻辑

- **统计型标准输入**：文本语料或标签表；以词项为最小数据单元。推荐字段：term_id、term、language、source_document、count、normalized_weight、category、time_window、source。
- **词项集合通常是扁平记录表**，可交叉映射到[编目型](../01-信息图形数据逻辑/03-编目型信息图形概念定义.md)，但不是必然的字母表型、层级型或地理型。
- **预处理**：统一编码、分词／词形还原、停用词、同义词归并、大小写去重；保留原始数据和清洗规则。中文需指定分词方式；英文要处理单复数与大小写；多语言不可直接用未经校正的词频互比。
- **纯海报型输入**可以只是文字片段与排版指令。若不具有可审查的计数／权重字段，准确标签应是“视觉词云／文字编排”，而非“词频分布”。

## B｜借用的统计方式与计算

| 环节 | 可操作规则 | 核验注意 |
|---|---|---|
| 计数 | 每个词项频数 f_i = 该词在选定语料内出现的次数 | 交代统计单位、全文/文档数、样本范围、日期 |
| 标准化 | 可用 p_i = f_i / Σf_j；或以文档频次 df_i 取代原始出现次数 | 须指明分母和分词口径，不能混用 |
| 排序 | 按 f_i / p_i / 自定义权重降序输出 Top N | 不要把因排版被放大的小词自动当高频词 |
| 视觉映射 | 示例：s_i = s_min + (s_max - s_min)×(w_i-w_min)/(w_max-w_min) | 映射**字号**，不等于字形面积精确成比例；权重相同需另行处理 |
| 长尾压缩 | 权重跨度悬殊时可先取 log(1+w_i) 再映射 | 在图注中标注使用对数缩放 |
| 验证 | 抽查词项、计数、排序、字号、碰撞和遗漏 | 未提供语料与权重时不做数值还原 |

统计词云本质不是柱状图、散点图、地图或严格面积图；其字号、字长、字重、词旋转均会影响视知觉。同一字号不同字符的实际视觉面积不一致。若需要精确比较，优先提供**排序条形图或词频表**配合原始数值。

## C｜视觉编码（点／线／面／体／符号／色彩）

| 编码维度 | 词云中的常用方法 | 数据与艺术表达的边界 |
|---|---|---|
| 点 | 单个词项的锚点、中心或布局位置 | 锚点常为布局算法产物，不是地理坐标 |
| 线 | 排列方向、文字行、隐性引导轴、放射线 | 没有明确数据关联时不代表时间或流向 |
| 面 | 词的墨迹轮廓、文本块、字距、疏密、留白 | 字符数量会影响占地面积；不可直接当数值面积比较 |
| 体 | 透视缩放、空间隧道、视深层次 | 视觉深度不等于真实三维或数值Z轴 |
| 符号 | 单词、字母、标点、重复主题词及语义标签 | 文字本身是数据载体，也可能是纯造型材料 |
| 色彩 | 可映射主题类别、情绪、正负极性；黑白高反差适合冲击力 | 没有图例时不应为颜色臆造类别含义 |
| 字体 | 字号、粗细、宽度、朝向、变形、分行 | 只有**编码规则清楚且可复算**时，才能解释为数值差异 |

**设计优化**：优先保证高权重词可读；控制旋转角度与单词重叠；留出足够的词间间距；设置主要视线入口；在长文字海报中保留稳定正文/活动信息区；为屏幕阅读提供可检索词表和替代文本。

## D｜数据与信息架构

**统计型**：语料定义 → 清洗/分词 → 词项与频数/权重表 → 视觉尺度/布局规则 → 词云总览 → Top N 精确表 → 来源、时间、方法说明。

**海报型**：主题词/活动文字 → 按语义或设计层级分组 → 字体系统与空间构图 → 主视觉焦点 → 功能性信息（时间、地点、署名）。

不同于数据整理的“编目型”，海报中的排列可以服从视觉节奏而不服从统计顺序。

## E｜视觉叙事架构

- **统计词云**：首先识别最显著的词 → 阅读次级主题词 → 形成主题概貌 → 回查词频表核实。
- **黑白文字密排**：从离散文字和反差入手 → 扫描中部的高密度文本块 → 到达下部重复、倾斜的“HOC”字样；叙事依赖节奏/层次，**未证实频数编码**。
- **放射透视文字海报**：大号字从四周向中心汇聚 → 视线进入中心深点 → 回到页脚读取活动信息；形态上的“向心”是透视表达，**不表示词频随距离变化**。

## 研究结论与误用检查

1. **“由文字组成的图像”不等于词云统计图**；至少应能指出词项、数值口径和视觉映射。
2. 视线焦点可由字号和空间透视共同控制，突出程度不一定是权重大小。
3. 海报可从词云借用密排与放射布局，但其首要任务是传播氛围／时间地点，而非统计揭示。
4. 对外宣传可称“词云风格视觉设计”；当作为严格数据可视化案例使用时，需要额外补充原始数据、图例或制作说明。
