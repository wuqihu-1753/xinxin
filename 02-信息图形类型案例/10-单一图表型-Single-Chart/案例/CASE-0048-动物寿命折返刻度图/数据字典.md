# CASE-0048｜数据字典

[基础数据集](./基础数据集.csv)有22行、6列。一行是图上明确印出的一处年龄刻度。

| 字段 | 定义 |
|---|---|
| `tick_id` | 本案分配的刻度标识 |
| `path_order` | 沿折返线从短寿命端读取的标注次序 |
| `tick_value` | 图上可辨认的数字刻度 |
| `unit` | 年，刻度表达寿命 |
| `source_id` | 用户截图标识 |
| `evidence` | E1为图面直接可见 |

[动物位置示例](./动物位置示例.csv)有4行、5列。区段界限对应图面相邻的标注刻度，记录视觉位置的读法。

| 字段 | 定义 |
|---|---|
| `animal_label` | 图上的英文动物标签 |
| `legend_class` | 按图例颜色判读的类别 |
| `lower_tick` | 可见相邻下界刻度 |
| `upper_tick` | 可见相邻上界刻度 |
| `evidence` | E2表示按版面位置判定所在区段 |

动物位置示例不视为寿命测量值。图示寿命口径为可预期达到的平均年龄。
