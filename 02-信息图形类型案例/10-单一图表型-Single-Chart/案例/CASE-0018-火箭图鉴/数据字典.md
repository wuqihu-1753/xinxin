# CASE-0018｜数据字典

[基础数据集](./基础数据集.csv)有10行、7列。一行是 `image(20261127-112508).png` 最底下一行的一个可辨型号。上方各行及每型号的小字参数本次未转录。行内序位作图面定位，原始排序字段尚待核。

| 字段 | 定义 |
|---|---|
| `record_id` | 本案分配的图面条目标识 |
| `model_label` | 截图可辨的型号标签 |
| `display_row` | 条目所在版面行 |
| `position_in_row` | 该行从左到右的位置，只作检索 |
| `graphic_as_of` | 整版标题所示的资料时点 |
| `source_id` | 补充截图标识 |
| `evidence` | E1表示图面可辨 |

年份字段记录整张图的资料时点。火箭的运营状态、运载能力和实际高度均需以版本与来源另表核验。
