# CASE-0047｜数据字典

[基础数据集](./基础数据集.csv)共 **7 行、8 列**，每行记录一条图上编号及其岗位或身份标签，取自用户提供的 `层级.png`。中文释义和说明是便于检索的转述。原图仅提供级次，直属关系未录入。

| 字段 | 类型 | 定义 |
|---|---|---|
| `item_id` | 字符串 | 本案分配的级次条目标识 |
| `level` | 整数 | 图面显示顺序，1在最上方，7在最下方 |
| `label_on_image` | 字符串 | 图面英文岗位或身份标签 |
| `label_zh` | 字符串 | 用于检索的中文释义 |
| `rank_basis` | 字符串 | 图面为何可记录为有序级次 |
| `annotation_summary` | 字符串 | 图面讽刺说明的简要转述 |
| `source_id` | 字符串 | 用户截图标识 |
| `evidence` | 字符串 | E1为图面直接可见的编号、位置或文案 |
