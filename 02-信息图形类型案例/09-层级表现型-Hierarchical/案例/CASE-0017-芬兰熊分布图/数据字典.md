# CASE-0017｜基础数据集字段字典

[基础数据集](./基础数据集.csv)共 **4 行、11 列**。一行是 `image(20261127-111341).png` 上可辨认的一条密度图例。原始数据口径、精确时点与区域底表尚待核验。

| 字段 | 类型 | 定义 |
|---|---|---|
| `class_id` | 字符串 | 本案用于引用密度档位的唯一标识 |
| `class_order` | 整数 | 图例自上而下由低到高的顺序 |
| `range_on_image` | 字符串 | 图例原文区间，保留十进制逗号及无限符号 |
| `lower_bound` | 数值 | 区间图示下限，统一小数点 |
| `upper_bound` | 数值，可空 | 区间图示有限上限，开放上限留空 |
| `upper_unbounded` | 布尔值 | 图示上限为无限时记 true |
| `unit` | 字符串 | 图示单位，每 1,000 平方公里的熊只数 |
| `color_description` | 字符串 | 按截图归纳的颜色名称，用于图面识别 |
| `period_on_image` | 字符串 | 图面提供的约略时间提示 |
| `source_id` | 字符串 | 用户截图标识 |
| `evidence` | 字符串 | E1表示图例可直接辨认 |

区间原文保留图面写法，数值列用于检索。当前不对相邻图示断点之间的数值进行分类。颜色名称是图面描述，不作为印刷色值。上一版空表的节点字段属于建模建议；本次按图上实际可见的色阶建档。
