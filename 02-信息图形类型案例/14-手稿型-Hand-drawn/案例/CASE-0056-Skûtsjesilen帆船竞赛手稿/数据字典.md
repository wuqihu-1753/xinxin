# CASE-0056｜数据字典

[基础数据集](./基础数据集.csv)有 **16 行、8 列**。每行对应一个可辨图面元素。模块与位置采用中文描述，直接可辨的原文保留原拼写。该表记录图面信息。

| 字段 | 定义 |
|---|---|
| `record_id` | 案例内唯一的记录标识 |
| `module` | 元素所属的图面模块 |
| `label` | 图中可辨的文字，或对可见元素的简述 |
| `record_role` | 元素在图面的角色，如模块、方向标签或引线 |
| `position_on_image` | 元素在版面上的大致位置，无坐标单位 |
| `value_on_image` | 与该元素直接关联且可辨的原图标记，缺失时留空 |
| `source_id` | 本次用户样图标识 `HAND-01` |
| `evidence` | E1 表示图面直接可见的信息 |

名录序号属于索引用途；图面方位与线路用来描述示意关系。
