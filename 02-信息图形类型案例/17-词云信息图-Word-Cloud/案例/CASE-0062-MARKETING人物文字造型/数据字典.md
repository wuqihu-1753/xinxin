# CASE-0062｜数据字典

[基础数据集](./基础数据集.csv)有 **7 行、9 列**。每行是一个可定位的词项、短句、排版实例、标题或图面特征。记录为从用户附图选取的图面观察，完整语料和权重尚未取得。

| 字段 | 定义 |
|---|---|
| `record_id` | 案例内记录编号 |
| `text_on_image` | 可辨原文、可读片段或对图面特征的描述，由角色字段区分 |
| `text_role` | 当前记录在图面上的角色 |
| `position_on_image` | 大致版面位置 |
| `relative_size` | 依据画面观察的相对字阶，未换算像素或字号 |
| `direction_on_image` | 基于画面识别的方向或排布 |
| `color_on_image` | 肉眼判读的近似颜色 |
| `source_id` | 用户附图标识 `WC-03` |
| `evidence` | E1 代表图面可直接观察 |

图面记录供版式复核。后续取得语料时可独立建立词项频数、文档频次或其他权重表，并注明统计口径与字号映射。
