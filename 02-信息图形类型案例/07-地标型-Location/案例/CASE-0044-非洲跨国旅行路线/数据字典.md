# CASE-0044｜基础数据集字段字典

[基础数据集](./基础数据集.csv)有 **7 行、6 列**，每行一条图面路线节点。来源为用户提供的 `地理2.png`（1200 × 1756 px）。

| 字段 | 类型 | 定义 |
|---|---|---|
| `anchor_id` | 字符串 | 图上路线节点唯一标识 |
| `place_label` | 字符串 | 图上故事卡中的俄文地名 |
| `place_zh` | 字符串 | 用于检索的中文译名 |
| `card_motif` | 字符串 | 外置卡片中可见的叙事图像 |
| `source_id` | 字符串 | 截图来源标识 |
| `evidence` | 字符串 | E1表示标签、节点或卡片配对可见 |

图面地名和卡片关系按截图转录；中文地名作辅助检索。[路线连接](./路线连接.csv)保存6条无向图示邻接。

## 路线连接

`路线连接.csv` 有6行、5列。每行是一组图上相邻节点，端点必须引用基础数据集的 `anchor_id`。

| 字段 | 类型 | 定义 |
|---|---|---|
| `edge_id` | 字符串 | 本案为连接分配的标识 |
| `endpoint_a_id` | 字符串 | 图示连接的一个端点 |
| `endpoint_b_id` | 字符串 | 图示连接的另一个端点，两列无方向含义 |
| `line_style` | 字符串 | 可辨识的图上连接线型 |
| `evidence` | 字符串 | E1表示图面可见 |
