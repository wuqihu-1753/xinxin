# CASE-0043｜基础数据集字段字典

[基础数据集](./基础数据集.csv)有 **9 行、6 列**，每行一条图面地标。来源为用户提供的 `地理.png`（736 × 980 px）。

| 字段 | 类型 | 定义 |
|---|---|---|
| `anchor_id` | 字符串 | 本案为地标图示锚点分配的唯一标识 |
| `place_label` | 字符串 | 图上可辨识的地标名称 |
| `annotation_side` | 字符串 | 注释在版面上的左右位置 |
| `graphic_relation` | 字符串 | 图示地标与外置注释的配对方式 |
| `source_id` | 字符串 | 截图来源标识 |
| `evidence` | 字符串 | E1表示截图可见 |

本表记录插画锚点与注释，未录入地理坐标、实地距离或统计值。
