# CASE-0015｜基础数据集字段字典

[基础数据集](./基础数据集.csv)有 **9 行、6 列**。一行是一条可辨认的补充截图标签，来源为 `image(20261126-061724).png`。课件原图和补充图在[原图来源说明](./原图来源.md)中各有记录。

| 字段 | 类型 | 定义 |
|---|---|---|
| `observation_id` | 字符串 | 补充截图中的观察记录标识 |
| `graphic_type` | 字符串 | 区域名或图例栏标题 |
| `label_on_image` | 字符串 | 截图可辨的原文 |
| `display_area` | 字符串 | 图上版面位置 |
| `source_id` | 字符串 | 补充截图来源标识 |
| `evidence` | 字符串 | E1表示截图可见 |

上一版空表的坐标字段可作为日后坐标建模参考。本次仅转录区域名与图例标题。站点坐标、站序、换乘关系及实时运营数据需另有资料。
