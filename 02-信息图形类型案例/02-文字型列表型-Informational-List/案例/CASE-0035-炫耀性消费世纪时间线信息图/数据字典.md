# CASE-0035｜基础数据集字段字典

[基础数据集](./基础数据集.csv)有 **25 行、6 列**。来源为用户本轮提供的 `文字(2).png`，每行记录一个可辨认的文字标签。

| 字段 | 定义 |
|---|---|
| `record_id` | 每条图面文字的独立标识 |
| `text_on_image` | 可辨认的英文标签；连字符与跨行空格作规范化处理 |
| `text_role` | 主概念、世纪标题、关键词、例证或结尾设问 |
| `century_no` | 图面归属的世纪数字；全局标题和结尾留空 |
| `source_id` | 本次图像来源标识 |
| `evidence` | E1表示文字本身与所列图面栏目可直接辨认 |

本表选录可辨标签，世纪字段记录作品编排的分组。世纪归属不作为该词项首次发生、仅在该时期出现或确切发生年份的证据。没有给字号或配色赋予统计权重。
