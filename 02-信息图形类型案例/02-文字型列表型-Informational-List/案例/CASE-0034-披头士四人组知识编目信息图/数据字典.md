# CASE-0034｜基础数据集字段字典

[基础数据集](./基础数据集.csv)有 **4 行、6 列**。来源为用户本轮提供的 `文字2(2).jpg`，每行记录一个可辨认的成员姓名标题。

| 字段 | 定义 |
|---|---|
| `member_id` | 成员条目的稳定标识 |
| `member_name` | 由图上姓名标题转录，统一为通常姓名大小写 |
| `text_role` | 姓名在页面中承担的文字角色 |
| `layout_position` | 相对于中心主视觉的图示位置，只用于检索 |
| `source_id` | 本次图像来源标识 |
| `evidence` | E1表示姓名及位置可直接辨认 |

位置以中央肖像为参照，用于查阅姓名与对应段落。行号不表示先后或排名。小图和底表的数值、单位与分母不在本次转录范围内。
