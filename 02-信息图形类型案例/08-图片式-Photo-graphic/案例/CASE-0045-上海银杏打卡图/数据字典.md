# CASE-0045｜数据字典

[基础数据集](./基础数据集.csv)有6行、6列。一行对应一个图上地点与照片卡的配对，来源为 `图片.png`。中心折线、街景底图和叶形装饰未作为地点另计。

| 字段 | 定义 |
|---|---|
| `subject_id` | 地点条目标识 |
| `display_number` | 截图索引和照片卡的匹配编号 |
| `place_label` | 截图英文地名 |
| `media_role` | 此照片用于识别地点、呈现场景 |
| `source_id` | 本次图面转录来源 |
| `evidence` | E1表示图面可见 |
