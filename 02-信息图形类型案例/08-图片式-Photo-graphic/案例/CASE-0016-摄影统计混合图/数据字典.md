# CASE-0016｜数据字典

[基础数据集](./基础数据集.csv)有 **34行、8列**。一行对应一个可辨识的图面统计标签，统一取自 `image(20261126-063636).png`。老龄人口模块17行、成人肥胖模块8行、NHS模块9行。

| 字段 | 定义 |
|---|---|
| `record_id` | 图面数值记录唯一标识 |
| `module` | 图面议题 |
| `entity` | 国家或NHS |
| `metric` | 图面所指指标 |
| `period_on_image` | 该模块直接标注的年份或区间；未标则留空 |
| `value_on_image` | 图面数字；千位分隔符去除 |
| `unit` | 图面百分比或NHS计数；人数口径待核 |
| `evidence` | E1表示本次补充截图可见 |

成人肥胖模块的年份在截图中未明确显示，留空。数据用于复核截图标注，原始统计的分母、地区定义和资料口径需另核。上一版空表中的媒体字段仍可用于另建摄影来源表。
