# CASE-0040｜基础数据集字段字典

[基础数据集](./基础数据集.csv)共 **15 行、9 列**，每行对应一条图面事件或明确状态。来源为用户提供的 `对比.png`（1207 × 2048 px）。本表为可读图面的选录。

| 字段 | 类型 | 定义 |
|---|---|---|
| `record_id` | 字符串 | 图面记录唯一标识 |
| `track` | 字符串 | 美国总统访华、中国领导人访美或第三国会晤 |
| `person` | 字符串 | 图中可定位的人物；中央模块记习近平与特朗普会晤 |
| `event_status` | 字符串 | 图示访问、明确未访问或图示会晤 |
| `start_date` | 日期，可空 | 图示起始日期，ISO 8601；明确未访问时留空 |
| `end_date` | 日期，可空 | 图示结束日期，ISO 8601；单日和明确未访问留空 |
| `place` | 字符串 | 目的国或中央地图标注城市 |
| `note` | 字符串 | 图面范围或定位说明 |
| `evidence` | 字符串 | E1表示图面可见，史实及口径待核 |

单日节点只填起始日期。明确未访问状态保留图上身份范围；图中未收录的年份不填零。各轨记录数反映本次选录。
