# CASE-0042｜基础数据集字段字典

[基础数据集](./基础数据集.csv)共 **10 行、5 列**，每行对应一条图面定性条目。来源为用户提供的 `对比3.png`（564 × 1018 px）。本表为可读图面的选录。

| 字段 | 类型 | 定义 |
|---|---|---|
| `record_id` | 字符串 | 图面记录唯一标识 |
| `mode` | 字符串 | Offline、Online 或两者共同 |
| `dimension` | 字符串 | 分析整理的生活情境维度，属E2归纳 |
| `statement_zh` | 字符串 | 图中文字的中文转述，指作品如何描述该情境 |
| `evidence` | 字符串 | E1表示图面描述可见，维度归纳为E2 |

情境维度由本案分析者归纳；中文文字为图面内容转述。单侧例证和共同说明分别保留，未为另一侧补写对应条目。
