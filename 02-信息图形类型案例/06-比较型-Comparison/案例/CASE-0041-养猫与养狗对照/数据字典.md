# CASE-0041｜基础数据集字段字典

[基础数据集](./基础数据集.csv)共 **12 行、8 列**，每行对应一条图面指标值。来源为用户提供的 `对比2.png`（407 × 625 px）。本表为可读图面的选录。

| 字段 | 类型 | 定义 |
|---|---|---|
| `record_id` | 字符串 | 图面记录唯一标识 |
| `panel` | 字符串 | 作品左右栏的对象标题 |
| `metric` | 字符串 | 所录图面指标或分组 |
| `value` | 数值 | 按图面转录的数值；百万单位按版面读数保留 |
| `unit` | 字符串 | 百万只、百万户、%或图示美元 |
| `denominator` | 字符串 | 适用的对象组；不适用则留空 |
| `note` | 字符串 | 图面原标签、冲突或限制 |
| `evidence` | 字符串 | E1表示图面可见，统计口径待核 |

分母未标或不适用时留空。猫栏45.3的标签冲突保留在备注；猫主饼图显示整数合计101%，保留各分项原值。原数据时期和费用周期待核。
