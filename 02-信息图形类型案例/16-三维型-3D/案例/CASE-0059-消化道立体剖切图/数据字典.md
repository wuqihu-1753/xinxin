# CASE-0059｜数据字典

[基础数据集](./基础数据集.csv)有 **14 行、9 列**。每行记录用户附图中的一个可辨元素或标注。图面位置为描述性方位，缺失值留空。

| 字段 | 定义 |
|---|---|
| `record_id` | 案例内唯一的稳定编号 |
| `module` | 元素所属信息模块 |
| `label` | 图面可辨标签或对可见元素的简述 |
| `record_role` | 图面的组织角色或标注类型 |
| `position_on_image` | 图面展示的大致位置 |
| `value_on_image` | 明示的数值或标记，无则留空 |
| `unit` | 原图可判读的单位，无则留空 |
| `source_id` | 本次用户样图编号 `3D-02` |
| `evidence` | E1 表示文字、图形及能直接核实的图面关系 |

图面标签及标注位置可用于版式研究。真实器官和组织的位置、尺寸以及量化测量均需要独立资料。
