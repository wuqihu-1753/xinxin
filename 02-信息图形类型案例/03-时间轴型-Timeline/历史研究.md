# 03｜时间轴型信息图形（Timeline Infographics）

## 参考仓库标准定义（2026-11-24）

> **当前统一定义入口：** [时间轴型信息图形 · Timeline Infographics](00-标签说明.md)。以下定义和A—E概述依照参考仓库的组织方式重述；本文件下方保留历次案例研究及理论深化，**不再以历史工作定义覆盖当前参考口径**。

**概念与识别边界：** 在可识读的时间参照下标记事件、阶段、时点或区间，回答何时发生、先后如何、相隔多久以及如何发展。时间轴属于时间化的表现形式；编年型则是更广义的先后／过程数据逻辑，不要求每个序列都有真实日期。

**基础数据主归属：** 时间是作品的关键组织数据时，主要基础归属通常为编年型；仅画有长线、箭头或阶段编号却无实际时间语义的作品，应优先判为流程链而非严格Timeline。

- **A 数据逻辑：** 事件型含 event_id、start_time、event_label、order_key；区间型另有end_time；多主体需 track_id；只有阶段顺序而无日期应明确标为“顺序示意”。
- **B 统计与计算：** 可计算相邻时点差、区间时长、阶段数量与某项随时间变化的数值；视觉等距不代表等时距，比例尺必须声明；数值折线不同于导览路线。
- **C 视觉编码：** 点表达时点，线提供时间参照，面表现区间与阶段，照片解释历史对象，图符表示事件类别，颜色区分主体和时期，文字标注时间精度和来源。
- **D 信息架构：** 事件与时间、轨道、精度、显示顺序分表或分字段保存；原始年份不能因折返或蛇形布局而被更改，图中日期的精度不得高于证据。
- **E 视觉叙事：** 背景→时间起点→关键节点→转折或并行变化→终点／当前状态。直轴、U形折返、蛇形都需明确路径和读序；时间相邻不能证明因果。

**分类限制：** 保序不要求等距；缺少时间的阶段链不等同严格Timeline；实际画面可能错序。本库CASE-0036直轴错序及CASE-0037折返构图均保留为具体案例证据。

## 历史研究与案例回写（原文保留）

> **版本 v0.2｜已依据上传课件图例核验**。已以课件示例作初步视觉核验。

## 1. 工作定义和边界

沿时间顺序组织事件、阶段、持续时间与变化，让读者看见发展过程。表现可为水平/垂直时间轴、蛇形路径、环形阶段、并行泳道、带插画的历史长图。

与 01 的**编年型数据逻辑**不同，时间轴型强调视觉呈现格式；一幅编年型图也可能采用表格、事件地图或序列分面而没有典型的“一根时间轴”。

## 2. A｜底层数据逻辑

事件字段包括 date/start/end、label、actor、category、importance（如主观赋权必须标注）。先核验时间先后和时点/区间，再讨论阶段划分。涉及多条发展线索时，使用实体ID或泳道分组；重复发生的事项可表示为事件序列或频率图。

## 3. B｜统计图形与计算

不一定使用数值统计：可只有按时间顺序的标记。若有数值，常加时间折线/面积、事件频率柱形、持续时间条、增长率或阶段构成比。统计计算须解释时间粒度，时间密度不均时不能靠节点等间距位置暗示真实年限。

## 4. C｜视觉编码

- **点**：事件节点/时刻；节点大小若表示重要程度，需明确是否为策展判断。
- **线**：主时间轴、并行轨迹、阶段连接；箭头说明先后，非因果证据。
- **面**：阶段区块和时长条；宽度若编码时长必须遵守时间比例。
- **体**：历史器物立体插画仅做场景注释，不能代替时间量尺。
- **符号**：事件物件、人物和地点的小图标辅助识别，保持风格统一。
- **色彩**：区分时期、事件类别或主体；同一主体跨时间保留配色连续性。
- **文字**：年份/日期为检索锚，节点标题简短，详述与来源放在次级层。

## 5. D｜数据/信息架构

总时间范围 → 单位/时间比例 → 阶段/泳道 → 节点事件 → 数值/图像解释 → 资料来源。不确定日期、跨年代事件与时间截断要有显式标记。

## 6. E｜视觉叙事架构

背景与起点 → 事件积累 → 重要节点与转折 → 前后比较/并行线索 → 当前结果或未来阶段。可通过转折节点改变视觉密度，但不可把时间跨度视觉歪曲而不说明。

## 7. 后续逐图观察清单

核验顺时/逆时阅读方向、比例时间/序列时间、日期精度、起终点、阶段分法、节点图标语义、人物/事件权重，以及可否从图中独立读出事实证据。若时间只是一组标签而实际按类别组织，标为“次要时间元素”。

## 10｜跨类型补充：同页独立时间层级与循环式时间线（2026-11-23）

- [CASE-0032 马年专题](../案例库/CASE-0032-马年生肖专题混合信息图.md)：年度出生统计的连续柱形基线、月历矩阵与春节日历条带同时存在，但只有日期时间有共同的“前后”语义，**不是统一刻度**。
- [CASE-0033 鸡与蛋生命周期](../案例库/CASE-0033-鸡与蛋生命周期混合信息图.md)：小时、天、周分别描述不同过程阶段，外圈箭头形成循环阅读路线。需区分“时间范围”与“结构流程”：各阶段间的视觉弧长不等于时间间隔。
- **判定规则**：时间轴型可以是编年整体的某个模块；当主体同时依赖解剖、图鉴、对比或说明卡时，主表现类型宜标为**混合型**，时间轴型为次级标签。可参照[混合型跨案例归纳](../01-混合型信息图形.md)。


## 11｜列表主导的世纪时间线：视觉导览线≠连续数值轴（2026-11-23）

- [CASE-0035 炫耀性消费](../案例库/CASE-0035-炫耀性消费世纪时间线信息图.md)采用**16—21世纪大字号时间锚点、左侧向下箭头、蓝色折线框、每段关键词列表/历史图像**，形成从历史到未来设问的纵向阅读路径。
- **主数据逻辑**属于编年：世纪次序改变会影响历史叙事；**主表现形式**则可以选择文字型/列表型：大部分知识信息直接在清单和注释中呈现。
- **时间轴型是交叉表现标签**：左侧箭头和蓝色折线起导览作用，但这不等于“消费量随时间的折线图”。时间节点间距、线框面积及曲折长度不是精确世纪时距或统计规模。
- **E 叙事**：概念界定→分段时代条目→现代消费符号→开放式未来设问。别把作者的趋势诠释写成统计已证的因果。
- **边界对照**：[CASE-0034 披头士四人知识编目](../案例库/CASE-0034-披头士四人组知识编目信息图.md)同样有大量标题、列表和图像，但没有类似的强制年代主线；不应只因为出现年号或图片便强判时间轴型。

## 12｜两张用户案例的反向完善：直轴错序与折返式时间轴（2026-11-24）

> **依据**：[CASE-0036 奎松市历史](../案例库/CASE-0036-奎松市历史时间轴.md) 与 [CASE-0037 皇家车站酒店](../案例库/CASE-0037-皇家车站酒店历史时间轴.md)。两幅作品以日期和历史事件构成历史长图，但属于两个不同的视觉组织原型。图面观察E1、设计意图推断E2、外部史料核验E3与无法验证E0分别标注；两例不构成阅读效率的实验结论。

### 12.1 定义补强：表现形式、时序真实性和比例尺度要分别判断

时间轴型信息图形以**可识别的年份／日期锚点、事件条目及方向性空间路径**表达历史先后、阶段或持续时间，允许直线、折返、环形、蛇形等版式。其基础阅读任务是“哪个事件在前、哪个在后”，但：

1. **时间轴视觉形式≠历史顺序已经正确**：CASE-0036使用竖直蓝轴却出现1941→1938、1978→1949、1954→1911等错序，是表现类型与数据逻辑执行质量分开评估的反例。
2. **路径折返≠时间倒流**：CASE-0037的早期节点沿左列下行，经过底部U形弯后再从右列上行到较晚年份，历史上仍是单向推进。
3. **视觉间距≠真实年份间隔**：若未明确给出比例尺，图片和年号的空间距离仅可视为排版序列，不能据像素/弧长计算Δt。
4. **日期角色必须明确**：某地点对应“规划、设立、建设、开放、迁址、纪念”可能有不同日期；不应把作品上列出的年份未经核验即认作建筑竣工年。

### 12.2 两种新确认的视觉组织模板

| 原型 | 阅读组织 | 案例与风险 |
|---|---|---|
| **纵向直线交错事件轴** | 一条纵向导览带＋沿两侧交错的年份、标题、文本与主题图像 | CASE-0036：视觉导航明确，**但原作品实有错序**；适合同时演示信息设计与历史审校的必要性 |
| **U形折返式连续年序轴** | 左侧向下→底部折返→右侧向上，附左右信息侧栏与中央档案图 | CASE-0037：折返节约竖版空间，须标起止点和转折方向，避免误判两列均向下 |

**不是新增02表现类型**；二者是“03时间轴型”内部的构图与组织模板。已有环形时间轴、世纪文字时间轴和生命周期交叉示例仍然保留，不能把所有弯曲路径当成周期/流程图。

### 12.3 A｜数据层与显示层分离的原子字段

| 表 | 推荐单值列（各列独立） | 用途 |
|---|---|---|
| **events** | event_id, event_name, time_value, start_date, end_date, date_precision, date_role, event_category, source_id, verification_status | 保存真实可核验事件，不把多日期塞在一格 |
| **layout_nodes** | event_id, display_order, path_order, path_segment, x_position, y_position, label_side, image_id | 保存显示次序和折返路径，而不是替换原始时间 |
| **links** | from_event_id, to_event_id, link_role | 区分先后导航、因果声明、图文标注与关联，不能由一根线自动证明因果 |
| **media** | image_id, caption, origin_url, creator, license_status | 记录图像信息与许可，不默认照片摄于邻近年份 |
| **date_conflicts** | event_id, depicted_date, verified_date, conflict_type, verification_source | 原样保留作品标注并记录审校事实 |

对CASE-0036特别要留存 original_time_label（图上年号）与 verified_date（经史料核查之日期），而不是直接覆写原作。官方史料确认奎松市正式设立于**1939-10-12**，与图中1938建城语境存在冲突，见[参议院《Commonwealth Act No. 502》](https://ldr.senate.gov.ph/legislative-issuance/commonwealth-act-502)及[奎松市官方历史](https://quezoncity.gov.ph/about-the-city-government/history/)；其它日期需逐条核验，勿泛化一个反例为所有年份均错误。

### 12.4 B｜数值边界与时间精度

- **离散事件排序**不必提供统计曲线。可以计算经核实的日期差、时段长度、某一条件下选登事件数，但**选登数量不是城市/酒店历史事件真实发生频率**。
- **等距事件序列轴**按顺序排事件，不能用等距画面距离声称等时距；**比例时间轴**才可按给定尺度读年份差。两张新案例均无可核算的统一时间比例尺。
- **多时间角色与不确定性**：date_precision记录日、月、年、区间或未知；日期有争议应标识，不应因为排版美观悄悄“纠正”来源。
- **历史相邻不代表因果相关**，蓝带、红带、喷溅、照片面积均不是连续量编码。

### 12.5 C｜点／线／面／体／符号／色彩／文字的编码分工

| 编码 | 从两例提炼的设计判断 |
|---|---|
| 点 | 年份作为事件锚点，地点与人物照片贴合事件；编号大小不能被理解为统计量 |
| 线 | 竖直连续、U形折返用于引导年序；折返处须显示方向，连接不等于因果 |
| 面 | 蓝色主轴与红色U形区域是时间结构容器，**面积/宽度并未编码年份差或影响力** |
| 体 | 历史地标/建筑摄影有空间质感，但不编码三维统计体积 |
| 符号 | 人物、场馆、雕塑等为历史对象索引，而非“每图标等于N个事件”的Isotype象形计量 |
| 色彩 | 单一主色强化时间轴的连续性；色彩统一不是历史事实等级的量化指标 |
| 文字 | 年份为一级定位，事件标题为二级，短说明与来源为三级；拆分两位数年份易引起跨行误读 |

### 12.6 D／E｜三项设计审计与两种叙事路径

1. **年份与史实审计**：针对每个事件核查时间值、日期角色、史料、图像归属，保留不同证据等级。不能因为视觉连续就认为时间正确。
2. **方向与排序审计**：直轴按阅读方向检查单调年序；折返轴必须按path_order而不是页面纵坐标检查。CASE-0036错序需保留为负面案例，CASE-0037须标左下右上的转弯阅读方式。
3. **量尺与图例审计**：判断位置是否真正映射连续时长，若只是分期/顺序，则明确采用“非比例事件序列”并避免计算像素时距。

**E叙事原型**：CASE-0036（拟议）“城市历史标题→逐年事件→地标图文”，但实际顺序错误导致叙事受损；CASE-0037“酒店历史主题→左列早期→底部转折→右列后期→中央历史语境”。直轴与折返轴均可容纳旁支人物/建筑图鉴，但主年序仍应可追踪。

### 12.7 Gestalt映射与读者测试（均为分析假设）

- **良好连续**：蓝色直轴/红色U形路径可能强化时间顺序的视觉感知；然而连续感与正确性不同。
- **邻近**：年份、标题和相应图像的靠近可辅助配对，交错布局与多个照片区域可能导致误归属。
- **相似、共同区域、图形背景**：相同年号样式、统一色带及强色差使页面成为共同专题；这些视觉规则不保证外部日期真实性。
- **测试任务**：①读者能否正确标起点/终点；②能否沿路径正确复述年代；③能否识别直轴错序或U弯方向；④能否把事件与图像、来源配对；⑤是否误把轴长当成时间差。记录正确率/时长/错误类型；目前**没有实测结果**。
