# CASE-0050｜数据字典

[基础数据集](./基础数据集.csv)有 **17 行、7 列**。一行是一项图面年代与事件记录，均来自用户提供的 `解剖.png`。

| 字段 | 定义 |
|---|---|
| `record_id` | 一条图面记录的标识 |
| `year_label` | 截图显示的年份数字 |
| `record_type` | 年代标题或明示年份的事件 |
| `group_year` | 该条所在的图面年代模块，年代标题行留空 |
| `label_summary` | 用于查阅的图面内容简述 |
| `source_id` | 补充截图标识 |
| `evidence` | E1为图上可辨的文字与位置 |

年代标题与事件分行登记。两个1853事件各有独立ID；1950同时有年代标题和具体事件，按各自类型保留。数据只表示图上陈述，不承担历史事实核验或操作说明。
