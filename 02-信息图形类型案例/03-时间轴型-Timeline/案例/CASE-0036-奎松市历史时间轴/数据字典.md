# CASE-0036｜奎松市历史时间轴基础数据集字段字典

[基础数据集](./基础数据集.csv)共10条图面转录记录。每行对应一个大字号年份节点，每格一个值。以用户提供的截图 `时间轴2(1).png` 为依据，`source_id` 统一为 `USER-IMAGE-0036`。

从画面顶部沿蓝色中轴向下，依次识别左、右图文模块。按原图位置保留逆序。

| 字段 | 类型 | 定义 |
|---|---|---|
| `event_id` | 字符串 | 图面节点唯一标识，编号依照原图阅读顺序。 |
| `event_name` | 字符串 | 图面可辨识的事件标题；省略号标注截图遮挡或标题缺字。 |
| `time_value` | 四位整数 | 图上大字年份，两段两位数字合写。 |
| `date_precision` | 枚举 | 图上年份的精度，当前均为 `year`。 |
| `source_id` | 字符串 | 图面转录来源标识。 |
| `display_order` | 正整数 | 沿所述阅读路径遇到的次序，从1开始；保留原图次序。 |
| `path_segment` | 枚举 | 直轴左、直轴右，按节点关联文字的位置记录。 |
| `visual_evidence` | 字符串 | 节点相邻的可见图像，用于定位年份和标题。 |
| `evidence_status` | 枚举 | `E1` 表示年份与可读标题可在截图中复核，具体史实见日期备注。 |
| `date_note` | 字符串 | 图上日期所指、可读性及待核事项。 |
| `verified_date` | ISO 8601 日期，可空 | 外部来源核实的关联日期，空值表示本次未录入核验日期。 |
| `verified_date_role` | 字符串，可空 | 外部核验日期对应的动作。 |

第2节点保留图上 `1938`，另录官方城市历史记载的正式设市日期 `1939-10-12`。菲律宾参议院立法资料馆的法案正文标题也列10月12日，页面的批准日期元数据则列10月11日。核验日期采用市政府关于签署与设市的明确记载。[奎松市政府城市历史](https://quezoncity.gov.ph/about-the-city-government/history/) · [Commonwealth Act No. 502](https://ldr.senate.gov.ph/legislative-issuance/commonwealth-act-502)
