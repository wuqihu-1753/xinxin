## 一图一档，保留历史正文

每一案例在其主表现类别下设`案例/CASE-XXXX-名称/`，对应参考仓库的一图一档结构，包含：
- `README.md`：案例身份、分类与完整正文入口；
- `分析.md`：**保存唯一完整版A—E案例分析**；原`案例库/`文件保留兼容跳转页；
- `基础数据集.csv`：**仅含字段表头、0条记录**，不是已完成数据集；
- `数据字典.md`：标注字段建议、目前数据状态、来源和缺失边界；
- `原图来源.md`：当前来源状态以及版权/公开存档限制。未经授权的原图不复制入库。

待获得能够逐值核实的数据，填入相应CSV并更新字典；只有存在可信图像再按许可保存真实`原图.png/jpg/webp`。**绝不把空CSV、示意数字或参考仓库同号CASE当成本仓库已经完成的数据。**
