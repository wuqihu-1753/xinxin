# CASE-0046｜数据字典

[基础数据集](./基础数据集.csv)有11条图示影片、5列。一行一个影片。原图为 `图片2.png`。

| 字段 | 定义 |
|---|---|
| `film_id` | 图上影片的独立检索标识 |
| `film_label` | 图面英文片名，统一标题大小写 |
| `year_label` | 版面所印年份 |
| `source_id` | 本次图面转录来源 |
| `evidence` | E1表示图面可见 |

[票房榜](./票房榜.csv)有3条图示数值、5列。`film_id` 关联影片主表；以图示的百万美元记录，统计日期未核。

| 字段 | 定义 |
|---|---|
| `film_id` | 引用基础数据集中的影片标识 |
| `rank_on_image` | 图中榜单排序 |
| `gross_on_image` | 图面票房数字 |
| `unit` | 按图面标注的百万美元 |
| `evidence` | E1表示图面可见 |
