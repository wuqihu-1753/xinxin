# CASE-0049｜数据字典

[基础数据集](./基础数据集.csv)有12行、11列，含底部8条高度标签、2条百格图预测项和2条用途环图项。每行对应一个可辨认的图面数值，来源为 `image(20261127-112455).png`。

| 字段 | 定义 |
|---|---|
| `record_id` | 本案分配的图面数值记录标识 |
| `module` | 版面中数值所在模块 |
| `entity` | 建筑、地域或用途类别 |
| `metric` | 图上数值表达的指标 |
| `value_on_image` | 图上数值 |
| `unit` | 图上单位 |
| `year_on_image` | 图示建筑年份或预测目标年，缺失则留空 |
| `year_role` | 年份所表示的作用 |
| `status` | 现有、设计目标、预测或用途构成等图面语义 |
| `evidence` | E1表示截图可见 |
| `source_id` | 用户截图标识 |

百格图计数分母为全球前100座，比例环分母为图示项目用途构成，两个模块分别查看。图上建筑年份与预测年份按不同语义记录。
