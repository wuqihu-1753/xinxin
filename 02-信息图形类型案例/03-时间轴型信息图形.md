# 03｜时间轴型信息图形（Timeline Infographics）

> **版本 v0.2｜已依据上传课件图例核验**。已以课件示例作初步视觉核验。

## 1. 工作定义和边界

沿时间顺序组织事件、阶段、持续时间与变化，让读者看见发展过程。表现可为水平/垂直时间轴、蛇形路径、环形阶段、并行泳道、带插画的历史长图。

与 01 的**编年型数据逻辑**不同，时间轴型强调视觉呈现格式；一幅编年型图也可能采用表格、事件地图或序列分面而没有典型的“一根时间轴”。

## 2. A｜底层数据逻辑

事件字段包括 date/start/end、label、actor、category、importance（如主观赋权必须标注）。先核验时间先后和时点/区间，再讨论阶段划分。涉及多条发展线索时，使用实体ID或泳道分组；重复发生的事项可表示为事件序列或频率图。

## 3. B｜统计图形与计算

不一定使用数值统计：可只有按时间顺序的标记。若有数值，常加时间折线/面积、事件频率柱形、持续时间条、增长率或阶段构成比。统计计算须解释时间粒度，时间密度不均时不能靠节点等间距位置暗示真实年限。

## 4. C｜视觉编码

- **点**：事件节点/时刻；节点大小若表示重要程度，需明确是否为策展判断。
- **线**：主时间轴、并行轨迹、阶段连接；箭头说明先后，非因果证据。
- **面**：阶段区块和时长条；宽度若编码时长必须遵守时间比例。
- **体**：历史器物立体插画仅做场景注释，不能代替时间量尺。
- **符号**：事件物件、人物和地点的小图标辅助识别，保持风格统一。
- **色彩**：区分时期、事件类别或主体；同一主体跨时间保留配色连续性。
- **文字**：年份/日期为检索锚，节点标题简短，详述与来源放在次级层。

## 5. D｜数据/信息架构

总时间范围 → 单位/时间比例 → 阶段/泳道 → 节点事件 → 数值/图像解释 → 资料来源。不确定日期、跨年代事件与时间截断要有显式标记。

## 6. E｜视觉叙事架构

背景与起点 → 事件积累 → 重要节点与转折 → 前后比较/并行线索 → 当前结果或未来阶段。可通过转折节点改变视觉密度，但不可把时间跨度视觉歪曲而不说明。

## 7. 后续逐图观察清单

核验顺时/逆时阅读方向、比例时间/序列时间、日期精度、起终点、阶段分法、节点图标语义、人物/事件权重，以及可否从图中独立读出事实证据。若时间只是一组标签而实际按类别组织，标为“次要时间元素”。
