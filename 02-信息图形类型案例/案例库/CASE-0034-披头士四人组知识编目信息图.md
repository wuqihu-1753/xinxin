# CASE-0034｜《Los Cuatro Genios / The Beatles》披头士四人组知识编目信息图

> **主表现类型**：[02 文字型／列表型信息图形](../02-文字型-列表型信息图形.md)（E1）｜次级表现：[01 混合型](../01-混合型信息图形.md)、[08 图片式](../08-图片式信息图形.md)。
>
> **用户图像证据**：本轮上传 `文字2(1).jpg`（399 × 587 px，竖版低分辨率）；图中文字可见西语标题 **LOS CUATRO GENIOS**、右上 **THE BEATLES**，以及 JOHN LENNON、PAUL McCARTNEY、RINGO STARR、GEORGE HARRISON 四个分栏标题。**原作者、首发日期、出版物和图片授权尚未通过独立原始页面核实**。
>
> **证据分级**：E1＝上传图片中直接可见的构图与栏目；E2＝从组织方式推断的阅读策略；E0＝小字数值、分母、统计数据出处、设计者与版权。公共仓库只存分析文字，不转载未获授权的作品图片。

## 1｜逐区视觉观察（E1）

| 位置 | 可见信息 | 组织功能与不能推出的内容 |
|---|---|---|
| 顶部 | 西语标题、导语；左右各有小圆形分区图；右上有 THE BEATLES 字样 | 先提示主题，再以小图形提供概要；分区比例及图例小字无法可靠判读 |
| 版面中心 | 大幅黑白人物肖像，周围嵌入成员文字说明 | **人物图像作注意力锚**，并不通过肖像面积编码成员贡献 |
| 中上四周 | JOHN LENNON、PAUL McCARTNEY、RINGO STARR、GEORGE HARRISON 标题与说明段落 | 同层级的四个成员知识条目，可独立查阅；其空间位置不是严格的出场顺序 |
| 中下左 | 黄色潜水艇形象插画及配套注释、一个局部圆形图 | 主题文化符号＋说明性／统计性子模块；插画尺寸不代表歌曲销量 |
| 中下中 | 若干分组的小人物头像／符号与连接式文字说明 | 重复条目和局部关联导航；不得仅凭连线断定亲属、因果或完整事件年代 |
| 中下右 | 横向红色条形/名录状模块 | 可见长短不同的条带；指标名称、量纲、排序依据、数值精度均待原图复核 |
| 底部左右 | 两块密排的多行多列表格，使用交替的暖红、青绿等色带 | 用表格做细项检索和横向对照，不能在缺少列名及单位时解释具体数值 |

**明确观察**：画面以“人物肖像—人物条目—知识模块—密排清单”为主要结构，并有圆形统计图、条形图、插画与表格辅助。尽管包含多图表，页面**不是以单个统计坐标系为核心**，因此“文字／列表型”为主表现，“混合型”为次级表现更贴切。

## 2｜双轴分类：为何是文字／列表型

- **数据逻辑主类**：[编目型](../../01-信息图形数据逻辑/03-编目型信息图形概念定义.md)。四名成员作为记录对象，姓名、简介等字段可并列查阅；下部表格也承担信息目录功能。
- **数据逻辑次类**：若下部确为歌目或作品年代，局部可能存在顺序／时间字段；**因图片小字不可核实，暂不把编年型当成确定主逻辑**。
- **表现主类**：**文字型/列表型**。核心阅读任务是按栏目识别成员、读取说明、检索表格。
- **表现交叉标签**：图片式（主肖像与潜水艇主题插画）＋混合型（饼状图、条形图、表格、人物照片同版整合）；图表数目多不自动改变主导阅读任务。
- **判定测试**：移除人物条目及底部清单，页面知识性大幅受损；移除一处小圆图，仍可辨识其人物主题。故此图**条目/说明优先于某一图表**。

## A｜基本数据逻辑（可重建字段，不等同获得原始数据）

至少存在以下编辑数据表：

1. **人物编目**：`member_id, member_name, brief_bio, role_or_topic, source, display_order`；四条成员简介互为同级，图中空间排位不是统计名次。
2. **专题/知识条目**：`fact_id, section_id, heading, explanatory_text, related_member_id, evidence_note`；不同栏目围绕同一组合归类。
3. **下部清单／表格**：`row_id, column_key, item_label, category, value?, unit?, record_source?`；实际列名与数值无法从现图逐条验证，**字段是重建建议**。
4. **局部统计模块**：`metric_id, category, amount_or_share, denominator?, reference_period?, original_source?`；饼图扇区和条形长度只有在原始图例明确时才视为合法数值编码。

主键是 **人物/栏目/条目**，而不是连续时间。主栏目为“同级条目集合”，底部表格是独立的检索层，不应未经验证强加父子树或因果网络。

## B｜统计图形、可能运算与核验边界

| 视觉形式 | 可以识别的图形原型 | 有数据后才允许的计算 | 不得臆断 |
|---|---|---|---|
| 顶端与中部圆形分区 | 饼形／构成占比图 | 构成比 `p_i=n_i/Σn`，需统一总体与时间口径 | 不能抄写看不清的百分比；不确认各圆图分母相同 |
| 右下短横条 | 条形长度比较 | 排序、差值、比率，前提是明确同一指标与零基线等 | 不能把条长直接翻译成销量、热度或排名 |
| 左右底部表格 | 文本/类别/数值混合表 | 分类查找；若列为同量纲数值，可做计数和对比 | 不能因交替色带推断正负、优劣或频率 |
| 四名成员 | 名称+介绍的目录 | 记录数量＝画面选登的四个姓名条目 | “四人”不是抽样统计量，不说明样本分布 |

**关键差异**：饼图、条图属于可定量表现的局部子图；成员姓名、栏目标签、人物肖像及黄色潜水艇并不因为出现在同页就成为统计图或 Isotype 计数。

## C｜视觉编码：点、线、面、体、符号、色彩和字形

| 通道 | 直接可见（E1） | 结构作用及风险（E2） |
|---|---|---|
| 点 | 小型人物图标、图例点、表格细项 | 条目定位和分类识别；点数不代表频数 |
| 线 | 栏目分隔、图表刻线、局部连接线 | 保持模块边界与视觉对齐；连线未必是因果关系 |
| 面 | 大型黑白肖像、信息底框、圆形分区、底部色带表格 | **图像面积**引注意、**表格色带**助检索；只有带图例的扇区/条长可考虑量值编码 |
| 体 | 肖像的摄影明暗与纸张复古材质感 | 氛围和视觉层次；无三维计量意义 |
| 符号 | THE BEATLES 字标、黄色潜水艇、小肖像、节奏/音乐题材装饰 | 建立主题语境；不等于标准化重复计数的 Isotype |
| 色彩 | 米黄旧纸底、黑灰照片、红褐标题、青绿/暖红数据区 | 强调标题和分区；**交替表格颜色不一定表示不同数据类别** |
| 字体/层级 | 西语大标题→组名/四人姓名→栏目注释→下方密排表格 | 实现“先识别主题—再找人—后查表”；下方小字号在移动端可读性较差 |

**可复用版式语法**：`人物主题主视觉 + 4个并列信息入口 + 图表侧注 + 底部明细查找层`。主视觉可大型，但不能压缩表格表头、单位与来源。

## D｜信息架构：由“阅读”到“检索”分层

`组合标题/导语 → 中心肖像和四位成员 → 成员说明+统计小模块 → 文化符号/辅助知识 → 底部两组明细表`。

- 上半部为**识别层**（人物是谁／围绕何主题），允许跳读四个成员。
- 中部为**解释层**（图像、段落与局部图表并置），在短文本和指标之间切换。
- 底部为**检索层**（细密双列表格）。尽管视觉面积相近，底表是补充查阅而非“第五、第六名成员”。
- 对新设计应保持`category, label, description, source`等字段分离，避免把编辑排版顺序当作事实排序。

## E｜视觉叙事与阅读路径（E2）

1. 从 **LOS CUATRO GENIOS / THE BEATLES** 明确主题；
2. 被大幅肖像吸引，从整体人物主题进入；
3. 按 **John / Paul / Ringo / George** 的栏头自主选读，不必遵守固定线性顺序；
4. 在小图形和黄色潜水艇等文化符号中获取扩展背景；
5. 最后视需求查阅底部密集条目、比较信息。

因此属于**“人物中心的百科式专题：总览→分类→专题补充→索引查阅”**。它**不是**清晰的主时间轴叙事，也不是四人实力排行榜。

## 3｜优点、局限与反向补充结论

- **优点**：统一视觉主题；大肖像帮助识别；四人姓名构成平级导航；双栏底表提供高密度查阅。
- **风险**：微型图表、正文和底表字号很小；低分辨率图片无法追溯比例分母；肖像的巨大视觉权重可能让读者误以为图中人物被评价为最重要。
- **反向规则 ①**：文字型可有统计子图；主类由**认知任务与信息访问方式**判定，而不是统计图是否出现。（本例＋[CASE-0010](CASE-0010-人物文字信息图.md)）
- **反向规则 ②**：列表不仅是竖直编号，还可由**多个平级人物入口＋辅助表格**组成。分类色带应表达分组或提升扫读，不应伪造排序。
- **反向规则 ③**：将信息划分为**主题识别/模块解读/细项检索**三层，有助于处理信息密集版面。
