# CASE-0037｜《Royal Station Hotel / Forres》皇家车站酒店折返式历史时间轴

> **主要表现类型**：[03 时间轴型信息图形](../03-时间轴型信息图形.md)（E1）｜**主数据逻辑**：[编年型](../../01-信息图形数据逻辑/01-编年型信息图形概念定义.md)，辅以[编目型](../../01-信息图形数据逻辑/03-编目型信息图形概念定义.md)的人物、建筑、酒店资料记录。次表现：[图片式](../08-图片式信息图形.md)、[文字列表型](../02-文字型-列表型信息图形.md)，局部专题整合可与[混合型](../01-混合型信息图形.md)交叉，不等同于量化复合图表。
>
> **素材证据**：用户本轮上传第二张图“时间轴.png”（510×727 px）；画面中央可读“Royal Station Hotel — FORRES, N.B.”，左右为历史人物、建筑、酒店、活动与时间标记。底部含设计署名但缩略图细小，**原设计者身份、出版年份、每条史实与原图片权利状态未独立核实**。公共仓库保存文字分析，不转载第三方海报原图。
>
> **证据分级**：E1＝视觉构图、可清楚辨识的主要年份、标题及信息位置；E2＝对路径、阅读和叙事角色的解释；E0＝历史事件的完整日期、逐条人物背景、原始作品发表与版权。下表年份是**图上标签**，不能当作外部已经验证的史实。

## 1｜直接图像观察：红色U形带与双侧时间导航（E1）

作品为竖版红／米白／黑三色复古编辑式海报。粗大的红色区域从左侧向下穿过底部圆弧，再沿右侧向上，形成显著的**U形折返构图**；中央建筑档案图和Royal Station Hotel字样作为视觉与内容中心。左侧以人物/酒店/俱乐部为主题的事件卡、右侧近现代节点及酒店生活相关信息并置，局部还有小日期标注和人物圆形照片，正文穿插历史档案影像。

| 页面区域及路径 | 图中可辨主年份（E1） | 说明 |
|---|---|---|
| 左侧自上而下 | 1866、1868、1873、1879、1899 | 早期历史背景、人物、建筑／酒店等条目；细部史实不凭缩略图扩写 |
| 底部U形转折 | 可见多个小日期和圆形节点 | 连接两段年序的折返区域，细小日期不保证逐一判读准确 |
| 右侧自下而上 | 1921、1960、1965、2016、2019 | 后期人物／事件、酒店活动或改造等主题；具体日期角色待查 |
| 版心 | Royal Station Hotel / Forres | 主题和历史影像集合；图像并非可按面积读数的统计图 |
| 左右边缘 | 多组图片、图注和文字资料 | 事件解释/人物资料/酒店历史线索，适合分区查阅 |

**阅读方向推断（E2）**：左列从早至晚**向下**，经过底部U弯后右列从早至晚**向上**，终点在右上方2019。由于视觉上也可能顺着各列习惯“从上到下”读，应在再设计时增加起点、U形转折箭头和终点的明确提示。**折返路径并非历史回到过去，更不是时间循环**。

## 2｜双轴分类与相邻边界

- **01编年型为主**：图中两侧年代构成早期→较晚事件的总体推进，但由于路径折返，物理坐标Y并不始终与时间正相关；真正的时间顺序应由沿路径的累计顺序决定。
- **01编目型作支线**：人物、建筑、酒店资料和群体活动各有标题、照片与短说明；需建立关联到相应事件ID，不能把一张图片无依据绑定到邻近的年份。
- **02时间轴型为主表现**：U形路径、密集年份及历史图片组织为一条延续性的历史阅读线。不是表示数值随时间变化的U型统计曲线。
- **图片式和文字型次表现**：档案照片、建筑剪影、人物肖像与说明文案提供具体内容。若研究其内容多模块混排可交叉标注混合型，但不能因图片多、红色面积大就说有多个独立统计坐标轴。
- **与15类编年×编目混合边界**：两类组织逻辑可以同时存在，主视觉阅读仍由时代路径主导；数据类型交叉不应替代具体表现判定。

## A｜底层数据逻辑：折返路径要分离时间值与画面位置

建议的字段蓝图，不是作品提供的原始数据文件：

| 表 | 每行内容 | 关键原子字段 |
|---|---|---|
| events | 一个历史事件记录 | event_id, event_name, date_value, date_precision, date_role, event_category, short_text, source_id |
| persons | 一个人物目录项 | person_id, person_name, role, source_id |
| event_person | 事件与人物的一对关联 | event_id, person_id, relation_type |
| media | 一张照片/建筑图示 | media_id, caption, related_event_id, image_origin, license_status |
| layout_nodes | 事件的画面位置 | event_id, path_order, path_leg, position_x, position_y, label_side |
| links | 模块解释连接 | source_event_id, target_event_id, link_role |

核心字段：**date_value** 是原始历史日期，**path_order** 是阅读序列，**path_leg** 为左列下降／底部转折／右列上升，**position_y** 是页面坐标。不能用position_y对全画面排序，也不能用U弯几何长度推导年代间隔。若日期只有年份，应保留 date_precision＝year。

一格一个原子值；一个事件关联多个角色/图片时，使用关系表多行保存，不把多个ID塞在一格。

## B｜统计图形、计算与时间尺度边界

- **事件年序不必有数值统计图**。可在核实史实后计算事件间隔（Δyear）、某一时段被选登条目数与阶段性内容密度，但这些数值只代表**作品选登事件**，不是该地所有历史事件的总体频率。
- **看似连续的红色U形带是阅读导航／分区背景**，没有可辨的时间刻度、统一单位和共同数据纵轴。路径曲率、长度与红色面积不构成时间测量或酒店经济规模编码。
- **年代先后与版面间距分离**：如1866到1868与1965到2016间隔不同，画面标签未给出严格等比例位置；如要制作可量化时间轴，必须按绝对年份映射，或者明确注明“等距事件序列展示”。
- **档案图片的来源条件**：照片与年代、人物/酒店事实的配对需要出处；不能仅凭相邻位置将视觉示例说成该年拍摄的照片。

## C｜视觉编码：色带、图像、节点与版式

| 通道 | 图中可见E1 | 功能推断E2及风险 |
|---|---|---|
| 点／节点 | 年份标签、小圆点、局部人物圆像 | 标记事件/补充来源，圆点数不代表事件发生总频率 |
| 线／路径 | 左下右上的U形走向、局部短引线 | 指示阅读方向与局部说明；线段长度不表示真实年份差 |
| 面／分区 | 大红色条带、米白背景、中央档案影像 | 红色视觉块组织整页历史模块；面宽非时间比例 |
| 体 | 建筑照片/历史人物影像中的透视 | 帮助识别时代/文化环境，不作量值编码 |
| 符号 | 人物圆图、酒店标识、档案插画 | 代表人物/文献主题，不是等单位Isotype统计象形图 |
| 色彩 | 红色主轴/照片套色＋黑色正文＋米白底 | 强烈视觉一致性；不同子区红色并非同一统计变量 |
| 文字层级 | 纵向拆开的两位数年份、大标题、人物小标题、微型说明 | 强化定位与旧报纸感；远距离容易漏看细节、年份需要整体拼读 |

**Gestalt线索**：良好连续（U形弧线关联两侧时期）、邻近（年份及相邻图片）、共同区域（红色历史带和居中照片集合）、相似（人物圆像与年份模板）、图形背景（红色与米白对比）。知觉连贯不自动证明史实或阅读路径绝对准确；特别是在底部转弯和右侧向上阅读时需测试方向误判。

## D｜信息架构：一条折返主线，多项档案旁支

建议将信息分为：（1）总标题/主体（Royal Station Hotel/Forres）；（2）左侧早期节点；（3）底部时间衔接与转折；（4）右侧较晚年代节点；（5）人物/建筑/照片的独立注释与来源。

**信息路由**：早期年代沿左侧下行→在底部转折→沿右侧上行至2019。中央档案图承载历史氛围与背景信息，不应让照片与事件时间标签的视觉重叠制造未经证实的因果与拍摄年份。

与普通竖向直轴相比，折返轴可以在短宽的版幅内嵌入较长时间跨度，代价是**阅读方向从“下”转成“上”**。建议明确以箭头/START-END标记，并在U弯处加强方向提示。

## E｜视觉叙事：历史发展不是生命循环

1. **主题建立**：酒店名称和中央历史档案建立记忆点；
2. **早期积累**：左侧1866—1899的事件/人物/建筑；
3. **视觉转折**：红带在底部回转，继续历史顺序（非时间倒退）；
4. **后期进展**：沿右侧自下而上阅读1921—2019；
5. **专题细节**：边缘说明与中央图像供局部跳读；
6. **收束**：右上方较晚节点作为终点，整体强调酒店及其关联环境的延续。

**关键判定**：视觉轨迹可回转，**历史时间并没有回到起点**。折返年表与鸡蛋生命周期的循环箭头（CASE-0033）具有不同时间拓扑；不能仅凭图形弯曲或闭合判断时间循环。

## 3｜优势、风险与边界

- **优势**：强烈的红白对比；折返布局压缩长年序；重复年份与人物照片形成统一阅读节奏；中央酒店史料图提供整体语境。
- **风险**：右侧向上阅读不是所有读者都会自动推断；年份拆成两行可能延长辨认；细密文字在缩小尺寸下难读；图中日期的具体所指、摄影出处、机构/人物史实尚未逐条核实。
- **主要视觉误判**：U形线不是经济数据趋势曲线，红色面不是重要性数值，折返不是回到过去，近旁照片不一定拍于对应年份。
- **出处声明**：设计者署名和发表来源尚未可靠读出；不根据“Royal Station Hotel”这一标题就混同其他地区同名酒店的历史资料。作品可见“FORRES”可确认地名标签，但其它外部酒店史料若未匹配原作，不应直接用于替换图中文字。

## 4｜反向补充规则与实践任务

1. **时间轴允许折返而时间事实不可逆**：序列顺序由path_order沿U形主线确定，不能全页简单按纵坐标排序。
2. **双尺度检查**：为每节点分别保留时间真实值与画面显示位置；必须声明等距事件序列或比例时间映射。
3. **路径方向提示是结构，不只是装饰**：START、END、箭头及底部转折标记决定读者是否能正确追踪年份。
4. **主题图像和历史证据分开**：照片可能服务气氛、识别、证明某建筑外观，须说明何种角色及出处。
5. **主线＋旁支**：人物/酒店/建筑的局部图文可跳读，但时间主线仍有明确年序。
6. **验证方案（未执行）**：让读者标出起点/终点并按顺序读出1866、1868、1873、1879、1899、1921、1960、1965、2016、2019，记录倒序误读；比较有/无转折箭头、年份标签分行/合行、压缩与放大的版本，保持事实不变。不能虚构效率提升比例。
