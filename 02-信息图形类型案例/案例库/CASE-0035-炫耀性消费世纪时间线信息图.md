## 2｜双轴分类与主次判据

- **主要数据架构**：[编年型](../../01-信息图形数据逻辑/01-编年型信息图形概念定义.md)。从16→21世纪以及“未来方向”的先后不可随意颠倒，否则作品试图阐述的消费变迁论证会受损。
- **次级数据架构**：[编目型](../../01-信息图形数据逻辑/03-编目型信息图形概念定义.md)。每个世纪内的商品、社会现象、品牌和消费方式组成可独立查阅的**时代关键词清单**。
- **主表现类型**：**文字/列表型**；作品的知识载荷主要由世纪标题＋蓝框关键词／例子列表＋简短解释承载。
- **次表现类型**：**时间轴型**，蓝色路径及大世纪数字提供连续阅读的视觉框架；另有历史图像和版块拼合，但不应因“多图像”就称为多种统计图表。
- **交叉判定**：这不是统计折线图，也不是“蓝线＝消费水平”的数据曲线；历史次序和清单解释是两套互补的结构，前者服务纵向叙事，后者服务每个世纪的横向知识检索。

## A｜基本数据逻辑：事件/时期与条目之间的关系

1. **时间阶段表**：`era_id, century_label, start_year?, end_year?, stage_heading, editorial_order, source`。阶段按世纪排列；**页上的卡片高度/距离并不代表各阶段精确时长**。
2. **时代消费符号条目表**：`item_id, era_id, keyword, item_type, interpretation, citation`。一个世纪对应多条名义型条目；商品、制度、价值观须标不同 `item_type`。
3. **实例与图像说明**：`example_id, era_id, title, image_description, contextual_note, image_source?, license?`。例如 Wedgwood、Le Bon Marché、Von Dutch 是主题案例，不是有统计代表性的随机样本。
4. **主张/推论层**：`claim_id, time_scope, claim_text, evidence_kind, verification_status`。从“物品炫耀”转向“体验、服务”的结论属于设计者历史诠释，尚需文献支持，不能写成页面已给出定量因果证明。
5. **导航关系**：`from_era, to_era, link_role`，蓝线链接主要传达阅读方向及模块组织，**不是商品流量、交易金额或历史因果强度**。

该图具备**“编年序列（纵向）× 编目清单（横向）”** 的双层数据骨架，展示文字型表现可以承载明确时序，而不必强制使用一个标准数值坐标系。

## B｜统计、计算及不能从图形推得的量

- **没有可见的连续量曲线/共同数值轴/来源数据表**。图中的 16TH—21ST 等数字是时间分类标签，不是某种统计数值大小。
- 若建立可核验的数据集，可按各世纪的收录条目数做简单计数，但那只是**作者选登数**；不能据此推断真实社会中消费种类、消费者比例或历史出现频率。
- **不允许**用蓝色路径长度计算时间、地位水平、消费金额或商品流通量。
- **不允许**将“某件物品在某世纪出现于图上”推论为其历史首次发明、普遍流行时刻或唯一年代。
- **不允许**把“21世纪体验转向”作为经过定量检验的普遍规律：这是作品的论述主张和设计概念。

## C｜视觉编码（点、线、面、体、符号、色彩、文字）

| 通道 | 图中事实（E1） | 信息作用与风险（E2） |
|---|---|---|
| 点 | 节点/视觉转折、历史示例小图定位 | 代表阅读站点，不代表人口或金额数量 |
| 线 | 蓝色左侧纵向箭头、折线连接、文本框边界、START/NEXT? | **阅读顺序＋主题关联＋空间导航**；线长和折点数不是交易/时间测量 |
| 面 | 粗蓝框关键词卡、粉红图片框、色块世纪标题 | 清单分组、时代边界、局部视觉强调；方框面积不是消费总额 |
| 体 | 部分照片/插画中的物件立体感 | 文化实例识别，不承担三维统计 |
| 符号 | 王室、郁金香、Wedgwood 陶器、商店、家电、时尚/手机等形象 | 时代的**例证符号**；不是等单位 Isotype 频数 |
| 色彩 | 高饱和蓝色线框＋粉红色历史图像/标签＋大面积白底 | 双通道：蓝色承担架构/信息列表，粉色承担主题/示例；颜色不代表“高低消费地位” |
| 字体/层级 | 超大粉色总标题、世纪数字大蓝字、蓝色大写短词条、小字号注释、底部未来问句 | 先阅读时间与关键词，再细读例证段；小注释存在可读性负担 |

## D｜数据与信息架构：二维索引的线性呈现

`主题定义 → 16世纪（身份）→17世纪（贸易/商品）→18世纪（制造）→19世纪（阶层/百货）→20世纪（现代消费）→21世纪（品牌/体验）→未来问题`。

- **一条纵向“时代顺序主线”**：左边向下蓝箭头与居中的世纪标题协调阅读方向。
- **一组横向“时代清单支线”**：每个时间段边上蓝框列出该时期的商品/概念，粉色图像进一步举例；列表对比的字段主要是“项目属于哪个时代”。
- **一个结论命题层**：下部从 CONSPICUOUS 到 “INCONSPICUOUS” 的标题呼应，建立从炫耀物件到体验消费的开放式讨论。
- **信息与叙事的区别**：时间是主排序键，消费名目是可查阅的条目，图像是例证，问句是作者的解释框架；四者不应该混为“同一种数据值”。

## E｜视觉叙事（E2）

1. **设问/界定**：页首概念与副标题交代“为什么购买某物也可能表达社会地位”；
2. **起点**：16世纪权贵社会与服饰、珠宝、仆从等符号列表；
3. **积累**：17—19世纪的贸易商品、工艺生产、阶层与百货商业等例证建立时代变化；
4. **转折**：20—21世纪加入品牌、旅游、生活方式和体验/服务清单；
5. **展望**：底部用“INCONSPICUOUS”/“THE WAY FORWARD?”构成**引导思考的设计提问**，不构成被统计证实的单一历史终点。

**叙事模式是“世纪推进＋清单列证＋概念反转”**。不同于人物百科图的非线性查找，本图**先顺着时间主线阅读，再在每个时代内按兴趣跳读关键词卡**。

## 3｜优点、风险与反向补充原则

- **优点**：一条显著蓝色路径稳定指向历史顺序；世纪文字是醒目的定位锚；每个阶段的关键词卡减少长段文字负担；图像提供跨时代的文化识别。
- **风险**：蓝线频繁转折可能产生“流程依赖/因果链”错觉；世纪之间间距并不编码真实年份比例；各时代选材有地域与史观偏差；部分英文注释很小；末尾“消费转向”是待论证假说。
- **反向规则 ①**：**文字列表可以搭载一条完整的编年骨架**，主阅读方式与数据逻辑可跨类型组合。
- **反向规则 ②**：蓝线可能是**导览线**而非统计曲线、因果边或流程箭头；判线先问“连接什么、表示什么、是否有数值量纲”。
- **反向规则 ③**：世纪标题是**顺序键/时间阶段标签**，不能误认为原始精度为1年的时间数据或等距连续轴。
- **反向规则 ④**：提出社会史观点时，将**可见案例、编辑归纳、未经验证的论证**分层，避免图像好看即等于史实被证实。

## 7｜案例深化：编年与清单双层结构及Gestalt（2026-11-24）

> 本节沿用原CASE中图像可见E1、分析推断E2、原始历史资料待核E0和Parsons作品出处E3的证据划分。不把作品选择的关键词当作消费史完整样本。

### 7.1 A／D｜数据表拆分：先时期、再条目与主张

| 表 | 原子字段（不同列） | 结构意义 |
|---|---|---|
| **eras** | era_id, century_label, era_order, stage_heading, date_precision | 16—21世纪的时代先后；精度为世纪 |
| **entries** | item_id, keyword, item_type, explanation, source_id | 分别收录物品、社会现象、身份符号、品牌或价值观 |
| **era_entries** | era_id, item_id, local_order | 一个时代多条词项用多行关联，组内位置只是展示顺序 |
| **examples** | example_id, era_id, caption, media_role, source_id, license_status | 图像实例（Wedgwood、Le Bon Marché等）的语义归属与版权 |
| **claims** | claim_id, claim_text, time_scope, verification_status, source_id | 从物质展示走向体验/服务的观点需要额外证据 |

**原子性**：图中TEA、TULIPS、SUGAR等应作为不同词项保存，不能以“TEA, TULIPS, SUGAR”充当一个单元格中的多个统计值。某词项在图中属于某一时期，不证明其首次出现或仅出现于该时期。**era_order（时期排序）和local_order（清单呈现排序）必须分开。**

### 7.2 C｜将蓝色路径的角色拆分

- **左侧蓝色纵向箭头**：主阅读顺序，表明从较早世纪向较晚世纪推进；不能从箭头的物理长度推算时间间隔。
- **蓝色关键词框**：同一阶段条目的共同区域；不是经济规模、消费额区间。
- **蓝色局部折线与连接**：页面导览和图文关联；没有依据将其看成统计折线或因果流。
- **粉红色历史图像**：给出相应时期的视觉实例，并非随机抽样产生的统计样本。
- **底部“INCONSPICUOUS”未来设问**：是作者设计命题，而不是已从图表量化推导的历史终点。

### 7.3 Gestalt视觉组织（仅在本02案例中记载）

| 线索 | 可见依据E1 | 合理推断E2与防误读 |
|---|---|---|
| **良好连续 Good Continuation** | 左侧蓝线一路向下并连接年代模块 | 引导时间主线；连续路径不意味着量值趋势 |
| **共同区域 Common Region** | 粗蓝框内同组词条 | 时期内部列表容易归组，但不证明词项之间有因果 |
| **相似 Similarity** | 重复的世纪字样、蓝框和粉图模板 | 读者可以识别阶段模板，而非推导“每世纪数量相同” |
| **邻近 Proximity** | 图例注释贴近示例图片，关键词围绕相应阶段 | 可能辅助识别归属，转折过多时也可能错读到邻组 |
| **连接性 Connectedness** | 蓝线穿接不同区块 | 必须先辨别导览/框线/实体关系；本图未提供交易流量或因果边的定义 |

### 7.4 E｜阅读路径与实验任务（未实测）

**路径**：主概念→16世纪→17世纪→18世纪→19世纪→20世纪→21世纪→当代消费方式与未来问题；同一世纪内的条目可按兴趣跳读，不必把每条关键词视为按先后排序的事件。

1. 指定一个世纪，观察读者能否找到该时期的蓝框清单与粉色例证，记录准确率、耗时和错配。
2. 以图中ROYALTY、TEA、APPLIANCES等词为题，询问它们在**本图的编排**中对应哪个世纪；不得把回答解释为历史首次出现时期。
3. 提问“蓝线是阅读路径还是消费额变化曲线”，记录误读类型。
4. 做有/无连续路径、有/无关键词围框的对照设计，保持原文和时代顺序不变；没有实测结果时只记录为设计假设。

**反向规律**：用“编年有序主轴＋时期内可跳读编目清单＋文化物证＋开放设问”承载知识解释，是文字/列表型与时间轴型的可重复组合，不等于一张统计消费额折线图。
