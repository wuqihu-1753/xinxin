# 05｜Gestalt视觉组织原则

## 核心约束

把知觉组织线索与信息对象的**真实关系**分开：接近不必然表示同类别，连线不必然证明因果。每条原则的实验结果要区分文献事实、设计推论及尚未测试；13张SVG是原创教学示意，不冒充受控实验或第三方原作。
