# 04｜Gestalt 格式塔知觉组织与设计原则

> **研究定位**：跨信息图形类型的视觉知觉组织方法，不是独立统计图表，也不是“用某一个视觉风格替代数据逻辑”。文档创建于2026-11-23。

> **分类边界**：本仓库自定 **13个核心研究条目**（经典分组7、后续组织4、整体组织2）。学界不存在普遍同意的固定条数；计数基于 Wagemans 等 2012 年综述的示例分类与设计教学需要。来源见 [参考资料](05-参考文献/00-参考资料与证据等级.md)。

## 使用与更新规范
1. 每条规则按 **A定义/B视觉线索/C信息架构/D叙事/E案例/F实践/G来源与边界** 维护。
2. 对“研究支持的现象”“设计应用推导”“未经测试的效果主张”分别标明证据等级。
3. 与 [02 CASE案例](../02-信息图形类型案例/案例索引.md) 交叉关联，不复制原作整图；示意图全部原创标示。
4. Gestalt 条件依赖、可能冲突，**不要把‘邻近永远压倒相似’写成普遍定律**。
5. 信息图审查先看数据与图例的真实性，再看布局的知觉组织；不为视觉简洁删除必要事实。
