### 分析语言约束
“从图中可见分区或连线”属于**视觉事实 E1**；“因此读者更快、更准确”属于**需要测试的假设 E2**。不要跨越证据等级。

### 从案例补充的设计方法

1. 分别记录水平与垂直间距，写明它们影响的是单个元素、某一列或更大的模块。像素记为附图观察值，实际版面需要复核。
2. 先确认数据或内容的真实归属。让标题靠近所属正文、数值靠近对应条形、图注靠近对象，再用较大的留白区分模块。检查容易跨行或跨组配对的地方。
3. 保持颜色、字号、形状、元素数量与画布一致，比较等距版和组间距增大版。自由分组任务记录读者实际分法，有确切语义归属的任务再记录正确率、耗时和错配类型。
