### 分析语言约束
“从图中可见分区或连线”属于**视觉事实 E1**；“因此读者更快、更准确”属于**需要测试的假设 E2**。不要跨越证据等级。

### 从案例补充的设计方法

1. 分别记录水平与垂直间距，写明它们影响的是单个元素、某一列或更大的模块。像素记为附图观察值，实际版面需要复核。
2. 先确认数据或内容的真实归属。让标题靠近所属正文、数值靠近对应条形、图注靠近对象，再用较大的留白区分模块。检查容易跨行或跨组配对的地方。
3. 保持颜色、字号、形状、元素数量与画布一致，比较等距版和组间距增大版。自由分组任务记录读者实际分法，有确切语义归属的任务再记录正确率、耗时和错配类型。

### 从案例补充的设计方法

1. **分开记录类别和位置。** 形状、颜色或符号表达类别，行列和留白帮助定位。案例 03 说明四个位置列可以同时承载两类形状。
2. **区分单变量对照和线索组合。** 测颜色时固定形状、朝向、尺寸和位置。若轮廓、明暗与位置共同支持分组，逐项注明作用。案例 01、02、04 提供不同对照条件。
3. **说明尺寸的用途。** 若尺寸编码数值，写明单位、尺度和映射。关键类别可以由形状与文字共同标识，并在灰阶或缩小状态下复核。
4. **按任务记录实际结果。** 先询问读者如何分组，再用有已知答案的图表任务记录识别正确率、耗时与错配。实测结果可链接到相应案例。

| [G03 案例 02：脚印形成的隐含路径](./G03-案例02-脚印形成的隐含路径.md) | 脚印的位置和朝向沿弯曲轨迹变化。研究间隙与离散符号的接续。 | 教学示例，未做用户测试 |

### 从案例补充的设计方法

1. **分别检查交叉、断开和转弯。** 交叉处检查读者沿哪段接续，间隙处检查前后朝向和间距，转弯处检查方向变化和整体走向。
2. **说明视觉路径的语义。** 路线能换乘或汇合时，可加节点与说明。折线遇到缺失数据时，应保留断开或标注估算。字符隧道的装饰纹理可记录为阅读引导，真实数据则单列来源与字段。
3. **用指定起点的追踪任务验证。** 保持图形样式、端点或对照标记及呈现条件一致，每轮只选择一个主要视觉变量，记录追错的分支、终点正确率和耗时。实测结果可回链到相应案例。

### 从案例补充的设计方法

1. **分开记录个体朝向、整体走向与共同目标。** 案例 01 的箭头指向同一片区域，案例 02 的个体朝向和群体排布轴分别提供线索。用于实际图表时，另核实方向、速度或流量是否有明确的数据字段和图例。
2. **注明其他分组线索。** 案例 02 的同色同形提示类别，案例 03 的弧线、尺寸和疏密引导追踪。可分别记录相似、连续与静态运动提示，并注明哪些属于图面观察，哪些属于设计推断。
3. **用动态对照测试运动分组。** 固定节点初始位置、颜色、形状、速度大小和开始时点，只改变运动方向，对比同向版和异向版。记录归组正确率、耗时和错配，注明运动造成的后续间距变化。研究同步时另设一轮，只改变元素开始变化的时点。

|---|---|---|
| [G05 案例 01：双圆框与跨界近邻](./G05-案例01-双圆框与跨界近邻.md) | 跨框两点相距约 99 px，同框两点相距约 319–321 px。观察围框与接近线索如何竞争。 | 教学示例，未做用户测试 |
| [G05 案例 02：双矩形框划分黑点阵列](./G05-案例02-双矩形框划分黑点阵列.md) | 框内列距约 50 px，最近的跨框列距约 60 px。观察围框与间距如何共同分区。 | 教学示例，未做用户测试 |

### 从案例补充的设计方法

1. **记录围框与距离是配合还是冲突。** 对照每个元素所属的框、最近邻及跨框距离。运用到仪表板或报告时，复核靠近边界的数值、图注和标签，避免错配到相邻模块。
2. **分别观察边界识别与框内归组。** 可辨的轮廓界定区域。同一模块的标题、数值、图形与图例采用共同区域时，要有真实归属作为依据。
3. **设置有框／无框对照。** 固定点位、颜色、尺寸和画布，只增删围框，记录读者的自由分组。有已知归属的图表任务可另测标签配对正确率、耗时与跨框错配。案例所列像素为附图尺寸下的测量值。
