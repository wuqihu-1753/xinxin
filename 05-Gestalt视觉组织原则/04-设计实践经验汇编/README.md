# 03｜设计实践经验：按证据积累，不造“万能排版公式”

## 实践积累体系
1. **理论参考**：13个规则的术语和研究限定，按原始文献保存。
2. **设计观察**：在某个CASE中直接可见的距离、对齐、围框、连接、色彩。
3. **设计假设**：如“加大组间留白可减少标签错配”，尚需实测。
4. **实测结果**：来源于真实任务、受众和版本对比的正确率/耗时/错误率等。
5. **经验复用**：记录适用条件、失败反例、屏幕/印刷尺度、不同字体语言。
