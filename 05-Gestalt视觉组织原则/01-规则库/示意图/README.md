# 01｜Gestalt 规则视觉示意案例库

> 本目录为**原创简化SVG教学示意**，不包含论文原图、不代表已执行的心理学被试实验，也不把SVG造型当作经过证明的普适阈值。

## 使用说明
- 13个规则各对应一张可编辑 `SVG`，文件名 `GESTALT-01.svg` 到 `GESTALT-13.svg`。
- 同一张图展示“强调本线索的结构”和“对照/弱化此线索的结构”。图中圆点、线条和箭头为**人工构造的讲解元素**，不携带真实统计数据。
- **Common Fate和Synchrony** 需要运动/时间的真实变化才能验证：相关SVG只是**运动方向或两个时刻的静态提示**，不能把它当作动态心理学实验证据。
- **元素连接 vs 均匀连接性**：前者示意离散节点之间的显式连接线；后者示意具有统一性质的连续区域。
- 若用户提供真实案例原图，必须首先在 [02真实案例分析](../02-信息图形真实案例分析/README.md) 登记来源，再决定是否在公开仓库存图。
