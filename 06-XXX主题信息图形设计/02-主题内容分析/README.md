# 阶段02｜主题内容分析：与大模型协作确定数据逻辑、类型、标签及风格

**目的**：先判断主题的信息关系，再为适合的图形形式贴标签，避免“看着像照片风就选照片型”等反向分类误判。

## 建议完成的四种独立判定

| 判定层 | 必须回答的问题 | 参照文档 |
|---|---|---|
| ① **数据逻辑（主、次）** | 对象主要按时间、父子层级、条目目录、字母检索、地理位置组织吗？是否属于网络/流程等其他结构？ | [01 五种概念](../../01-信息图形数据逻辑/01-编年型信息图形概念定义.md) |
| ② **表现类型（可多选）** | 是文字/列表、时间轴、照片、混合、词云、比较、解剖，还是其他编号类型？ | [02 18个条目索引](../../02-信息图形类型案例/案例索引.md) |
| ③ **基础设计方法（横向）** | 是否需要固定换算单位的重复象形图（ISOTYPE），而非普通装饰图标？ | [02 第18项ISOTYPE](../../02-信息图形类型案例/18-ISOTYPE象形统计设计方法.md) |
| ④ **视觉风格（可多选）** | 扁平矢量、摄影、手绘、简约科研、编辑信息图等，基于受众/媒介如何实施？ | [03 风格卡](../../03-信息可视化风格与RAWGraphs源码研究/10-信息可视化风格设计卡与交付标准.md) |

## 与大模型的工作方式

使用 [对话提示模板](与大模型协作的分析提示模板.md)，以已有调研为输入，要求至少给出**两种不同组织方案、理由、适用数据、优缺点和反例**。输出不能将模型的猜测当作事实。

## A–E 五维检查
- **A 数据逻辑**：时间索引、类别、层级、坐标等怎样组织？
- **B 统计/计算**：频数、比例、增长、排名、词频、关系权重等是否真的可计算？
- **C 视觉编码**：点、线、面、体、符号、色彩、字体如何承担语义？
- **D 信息架构**：主题—模块—局部信息怎样排列？
- **E 视觉叙事**：阅读起点、关键发现、局部解释和结尾是什么？

**输出**：[主题类型和风格决策卡](主题类型与风格决策卡.md)，保留被否决的备选方案，避免因后续新增数据而无法追踪决策。
