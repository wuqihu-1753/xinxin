# 与大模型协作的主题分析提示（可复制使用）

> 先填入阶段01的真实调研内容与资料链接；未提供素材时，不要求模型编造事实或数据。

```text
我正在设计“【XXX】”主题的信息图形。
目标受众：【填写】；用途/媒介：【填写】；时间/地理范围：【填写】。
已确认的调研问题和来源：【填写；可附资料】
已有字段或数据样本：【填写；没有则明确写“尚未搜集”】

请严格按我的信息可视化知识体系提供分析：
1) 判定主、次数据逻辑：编年、层级、编目、字母表、地理，或其他（说明为什么）。
2) 从02库的17种表现形式中提出2–3种组合选择，并说明文字型、照片型、词云、混合或时间轴等标签如何适用；不能硬贴标签。
3) 另外判断ISOTYPE作为第18项“基础设计方法”是否适合。只有固定图标数量换算有意义时才推荐，不要把普通小图标一概当ISOTYPE。
4) 比较平面矢量、摄影、图文编辑式、手稿等视觉风格的效果、局限、可读性、版权条件。
5) 按 A 数据逻辑 / B 统计方式 / C 视觉编码 / D 信息架构 / E 视觉叙事 分析。
6) 给出两个结构差异明显的选题方案，每个写：所需字段、数据来源类型、主张、读者疑问、叙事模块、适用图形、风险。
7) 将“已从资料证实”“设计建议”“尚未查证”逐项标注。
请先指出缺失的最关键资料，不要虚构任何真实值、作品作者或来源。
```

## 模型输出的核验
- 是否对每个标签给出**符合/不符合的判据**？
- 风格词与数据类型是否被混为一类？
- 需要数据支撑的结论是否有可能搜集到可靠数据？
- “词云图”是否有真实词频或明示只是实验性文字排版？
- “照片型”是否确实以摄影证据/图像叙事为主体，还是仅用一张装饰图？
- “ISOTYPE”是否有重复、等尺寸、量化单位和图例？
