# 阶段06｜视觉编码与风格表达（设计重点）

> 与05不同：05决定“说什么及先后关系”；06决定“**如何让读者通过视觉准确且高效地读出来**”。本阶段允许大胆设计，但图形量化规则必须可追溯。

## 1. 视觉编码的分类

| 编码维度 | 设计手段 | 信息作用 | 必须检查 |
|---|---|---|---|
| **点** | 坐标点、标记、节点、符号位置 | 地点/对象/数值位置 | 坐标系、重叠、标记是不是数据量 |
| **线** | 边、连线、曲线、时间轴、流带 | 关系、路径、方向、趋势 | 线是示意还是量化；线宽与单位 |
| **面** | 柱形、色块、地图区域、分层面积、形状 | 比较、组成、分类 | 面积/长度对应数值；基线/颜色图例 |
| **体** | 透视、3D示意、剖面、等距形态 | 空间结构与主题形象 | 体积是否真编码数据；避免装饰性透视误导 |
| **符号** | 图标、图例、ISOTYPE象形统计、箭头 | 类别识别、数量重复、方向 | 一图标是否=N单位；与纯装饰区别 |
| **色彩** | 类别色、顺序色、发散色、背景与重点色 | 分组、数量等级、层次与情绪 | 色盲可区分性、局部图例、同色多义 |
| **文字** | 字族、字重、字号、字距、行距、段落、数字 | 信息层级、注释、精确读数 | 主次是否清楚，长文/小字号可读性 |
| **图像** | 摄影、插画、剪影、解剖图、纹理、图鉴 | 事实图像/空间解释/主题叙事 | 来源、版权、真实性、是否改动统计比例 |
| **统计图形** | 柱形、折线、矩阵、蜂群、桑基、树图等 | 数量或结构的准确编码 | 字段类型、单位、算法与统计结论 |

## 2. ISOTYPE 与普通图标的区别
[03独立ISOTYPE专项](../../03-ISOTYPE信息图/00-ISOTYPE概念与方法.md) 是横向基础设计方法，**不是 ISO认证**：其典型机制是以**等大符号重复次数**映射数量，必须声明一枚图标对应多少单位和舍入规则。普通扁平图标、照片排布或图鉴**不自动属于ISOTYPE**。

## 3. 从04统计图形与RAWGraphs研究借用技术与表现
参照 [RAWGraphs 可视化风格卡](../../04-统计图形分析/RAWGraphs源码与风格研究/10-信息可视化风格设计卡与交付标准.md)、[图表机制图谱](../../04-统计图形分析/RAWGraphs源码与风格研究/03-32种图表的机制与风格图谱.md)。RAWGraphs擅长统计可视化及SVG基础导出，报纸式编辑叙事和摄影/插画图形仍需独立设计。

## 4. 建立视觉样式规范
在 [编码映射与设计规范模板](01-视觉编码矩阵/视觉编码与版式规范模板.md) 中逐一填写每个叙事模块的编码方式、颜色、字体、图例、留白、图像风格及导出需求。

优先级：**数据准确性与可读性 → 结构清晰 → 视觉节奏与层级 → 个性化风格**。不因为选用扁平矢量就删除统计必要的轴和单位；也不因为使用摄影就假定它是照片型信息图。
