# 设计表现形式与基础方法：避免混淆的标签选择

## 先判断信息结构，再选风格

| 研究问题 | 优先检查的02表现类型 | 风格可选项 | 方法与边界 |
|---|---|---|---|
| 多时期事件 | [时间轴型](../../../02-信息图形类型案例/03-时间轴型-Timeline/历史研究.md) | 平面、摄影、编辑式 | 时间间距与事件选择需注明 |
| 长篇知识介绍 | [文字/列表型](../../../02-信息图形类型案例/02-文字型列表型-Informational-List/历史研究.md) | 字体排版、图片卡片、扁平 | 条目顺序与正文层级是核心 |
| 图像作为证据 | [图片式](../../../02-信息图形类型案例/08-图片式-Photo-graphic/历史研究.md) | 摄影、影像档案、蒙太奇 | 图片真实性与来源需核实 |
| 某主题多模块互证 | [混合型](../../../02-信息图形类型案例/01-混合型-Mixed-Charts/历史研究.md) | 编辑式、插画、摄影混合 | 不同数据单位需局部图例 |
| 实际有词频 | [词云图](../../../02-信息图形类型案例/17-词云信息图-Word-Cloud/历史研究.md) | 字体、单色/彩色、放射式 | 没有词频不应冒充统计词云 |
| 需要整体—部件知识 | [解剖型](../../../02-信息图形类型案例/12-解剖型-Anatomical/历史研究.md) | 手绘、水彩、矢量、摄影 | 空间部件关系优于装饰风格 |
| 用同类小图标对比数值 | 可叠加比较型/混合型等 | 扁平或历史象形风格 | [ISOTYPE第18项](../../../03-ISOTYPE信息图/00-ISOTYPE概念与方法.md)要求同大小重复、量化换算与来源 |

**三条轴分别在02决策卡记录**：数据逻辑 / 主要表现类型 / 基础设计方法与视觉风格。平面风格或照片风格只是视觉处理方向，不代替数据逻辑判断；ISOTYPE虽然为02编号18，**其本质是跨类型方法条目**。
