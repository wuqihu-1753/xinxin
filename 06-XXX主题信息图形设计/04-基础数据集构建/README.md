# 阶段04｜基础数据集构建（核心约束：一列一变量、一格一原子值）

> 对“1列中只有1个数据”的可操作定义：**一个字段列只表达一个独立变量；每条记录在该列的单元格中只存一个原子值**。一列可以有多行记录，但不能在同一单元格拼接多个不相干字段。每行代表**一个一致的观察单位**（例如一个地点在某年份的一条记录）。

## 1. 最基本的规范

| 正确示例 | 不合规范的示例 | 为什么 |
|---|---|---|
| `名称=地点A`，`经度=...`，`纬度=...` 分为3列 | `地点A(经纬度)` 合并在一格 | 名称和两项坐标应可独立映射 |
| `名称`、`GDP数值`、`GDP单位`、`年份` 各一列 | `某地 GDP 100亿元（2024）` 塞一格 | 不便正确计算/过滤/统计 |
| `图片URI` 为单个文件路径，`图片说明` 为单独字段 | 一格放3张图片链接 | 不满足单格单值规则；多图片应拆为附表 |
| `关键词` 列每格一条词语，`词频` 另列 | `关键词A/关键词B/关键词C` 一格 | 无法可靠统计词频 |
| `测量值` 数值列，`类别` 标签列 | `85分（优秀）` 一格 | 两个语义字段应分开 |

**原子性不是说文本必须只有一个汉字**：一个采访句子、一个文件URI可以是单个“文本字段值”；若要按词频、人物等细项分析，应另建分词/实体表。

## 2. 字段类型清单

- **名义型**：地名、名称、颜色、类别、ID。不要对类别编码1/2/3直接求均值。
- **顺序型**：等级、顺序编号（需说明排序含义），等级差不一定等距。
- **量化型**：计数、比率、金额、距离、连续测量；标单位、精度、有效值域。
- **时间型**：ISO日期或时间戳、年份；记录时区或历法/精度。
- **坐标型**：纬度和经度分别存独立数值列，另记坐标参考系（例如WGS84）。
- **图像型**：一格仅一条文件路径/URI/图像ID，图片元数据、版权、描述可另列。
- **文本型**：一格一个文本记录或一条文献段落；不要把多来源拼入一格。

## 3. 两个不同的结构

**基础表（clean / tidy）**：用于清洗、复用、核对字段类型；**叙事派生表**：用于选定问题的字段组合、分组/聚合、数据变换，保存来源和公式。**不得为视觉故事直接覆盖基础表**。

- 基础数据模板：[基础数据表模板.csv](基础数据表模板.csv)（只有表头，没有虚构观察值）。
- 解释字段的字典：[字段字典模板.csv](字段字典模板.csv)。

## 4. 数据表结构

```text
record_id → 单条观测的唯一键
entity_name → 名义型
longitude → 数值型：经度
latitude → 数值型：纬度
metric_value → 数值型：观测量
metric_unit → 类别/单位
year → 年份
image_uri → 单图片URI（可空）
text_note → 单条文本备注（可空）
source_id → 来源台账对应的编号
```

不是所有项目都需要全部字段。按实际主题删除无用列并补上业务字段，**但不能把经纬度、不同单位、多个数据点混写在一个单元格**。如果同一实体有多个图片或年份记录，用独立多行或关联子表，并写清主键。

## 5. 完成条件
- 一列一变量、一个单元格一个原子值；
- 有字段字典和主键，缺失值与重复记录有解释；
- 来源能回溯到阶段03；
- 量化字段和单位可复算，不混用日期与字符串；
- 任何派生计算都有公式与分母，能从基础表重建。
