# 阶段07｜信息轮盘测试（保留待完善）

> **根据项目要求，正式“信息轮盘”的维度、权重、判分标准与实施方式目前尚未提供。这里仅建立可填写的阶段，不虚构一个已经被验证的轮盘模型。**

## 本阶段现在可做什么
- 记录待测试的信息图形版本、目标受众和测试问题。
- 建立“轮盘指标尚待确定”的检查记录；
- 在未建立正式量表前，可以先进行基础事实核查、可读性检查，但不能称为“信息轮盘评分”。

## 待用户后续补充的信息
1. 轮盘维度名称、定义及每维评价目标；
2. 权重与分值范围（是否等权/需要基准图）；
3. 评价主体（用户、专家、同学或设计者）与样本量；
4. 操作方式、判据和通过阈值；
5. 测试数据收集、复测与设计迭代规则。

## 使用
先填写 [测试记录占位模板](测试记录占位模板.md)。**目前状态必须保持“轮盘定义待定”**，只在你提供具体标准后补充正式评分轮盘。

可以单独做的非轮盘基本检查（不构成正式得分）：事实与来源是否准确、图例能否识别、图文是否对应、单位能否找到、主要结论是否能从数据得出。
