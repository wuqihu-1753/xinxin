## 1. 工作定义：作为第18个条目，仍然是一种基础设计方法

**ISOTYPE** 是 *International System of Typographic Picture Education* 的简称，源于 Otto Neurath 团队20世纪20年代在维也纳开发的**Vienna Method of Pictorial Statistics（维也纳图像统计方法）**，1935年使用 Isotype 名称。

它是一种**将统计事实转换为标准化、可重复的象形符号，让图形辅助跨语言的信息解释与教育**的方法体系。它不仅涉及图标美术风格，还涉及：选择与转换数据、选择图形单位、符号词汇规范、比例一致性、系列间可比性、图例和文字解释、公共教育目的。

- **Otto Neurath**：发起和指导这一视觉教育方法；
- **Marie Reidemeister（后为 Marie Neurath）**：担任 *Transformer*（把统计材料转换为视觉陈述的设计研究角色），也参与 Isotype 名称形成；
- **Gerd Arntz**：发展了简明、统一、可重复的象形符号视觉语言。

**重要名称边界**：Isotype 不是 ISO（International Organization for Standardization）标准的缩写；`ISOTYPE ≠ ISO认证`。即使现代案例采用平面小图标，也不能自动宣称其为历史 Isotype 正统作品。

## 2. 最关键的可验证规则

1. **象形符号是语义单位**：图标与类别/实体之间有明确对应关系；应优先使用易读、形态稳定、可复用的简化图标。
2. **用重复的等尺寸图标表现更大的数量**：不是把单个图标随数值任意放大。传统 Isotype 语法的重要原则是数量多→相同尺寸的符号多。
3. **有公开、统一的换算单位**：例如 `1人形 = 1000人`、`1图标 = 10%`；不能只写“很多人形”就认定有统计映射。图标“一个表示一个对象”和“一个表示一千个对象”都须交代。
4. **图例与比较口径一致**：对象、单位、时间、地域、样本和图标对应方向必须一致；不同系列的图标数量才可比。
5. **图形转换有依据**：分析者应记录数据→选取/聚合→单位化→符号阵列→解释文字的链条，而不是只检验图标画风。
6. **不确定性与尾数透明**：缺少半图标或取整方案时应显示真实数值/误差，不应把量化视觉画得貌似精确。

> **示意计算（本库教学推导，不是历史原作的统一数学标准）**：当类别数值为 `v`、一个符号代表 `u` 个单位，完整图标数可按事先公布的规则取整：`n = round(v/u)`；图形隐含的近似值 `v_hat=n*u`，舍入误差 `e=v_hat-v`。例如 350 人、`u=100`，若用3或4个完整图标都会发生误差；应改用更小的 `u`、明确部分符号规则或保留数值标签，**不得悄悄写成350刚好由4个100人形表示**。

## 3. 与普通象形符号图、图鉴和信息图形类型的边界

| 对象 | 核心是什么 | 是否可直接确认 Isotype |
|---|---|---|
| **Isotype / 可验证的现代Isotype式象形统计** | 等尺寸、重复符号＋每符号对应数量＋明确源数据和比较条件 | 满足规则并核实来源时，可标“方法已确认”；若仅相似应标“Isotype启发式” |
| **Pictogram / 图标** | 用简化符号表示人、物、事件或功能 | **不能**，没有数量映射也可能只是图标 |
| **Icon chart / 象形统计图** | 若已定义一枚图标代表N单位，可以形成 Isotype-like 机制 | **候选**，还应核对图例/尺度及源数据 |
| **图鉴/目录** | 一图一物种/一条目，服务分类检索 | **不能自动认定**，重复的是条目模板而非数量单位 |
| **装饰性重复图案** | 表示纹理、情绪、品牌/地理轮廓 | **不属于**有证据的 Isotype 数量统计 |
| **Mixed、Timeline、Comparison 等** | 整页信息组织与表现类型 | **可交叉使用**此设计方法，仍按原主要类型分类 |

**三层模型**：`01 数据组织逻辑` → `02 表现形式（01–17）` → `02 第18项特殊方法 / #ISOTYPE 横向标签`。例如“地理数据逻辑＋混合表现形式＋Isotype单位符号”可以同时成立，三者互不替代。

## 5. 用 A–E 框架分析这种“基础设计方式”

- **A｜数据逻辑（非新数据类型）**：支持比较/时间/编目/地理等结构；若实施量化，至少含 `category, value, unit, pictogram_id, glyph_unit, source`；跨年度再加 `year`。
- **B｜统计/运算**：按 `u` 将数量转换为重复次数，公开舍入规则、比例、归一化、分母和误差；禁止按“图标面积大小”替代“等大符号数量”。
- **C｜视觉编码**：平面轮廓与简明图形、等大小符号、多次复用、对齐、固定间距、类别色、局部图例。点/面对应符号重复，线通常用于序列和排列；图标立体渐变不是量化所必需。
- **D｜数据／信息架构**：同一维度下以一行/一组图标表达一个类别，排列尺度与分组规则稳定；复杂说明采用标题、数值、图例及文本辅助理解。
- **E｜视觉叙事架构**：读者先通过通用符号识别事物，再借数量重复进行比较，最后联系文化、经济或社会事实得出有来源的认识；应避免把图形装饰冒充统计证据。
