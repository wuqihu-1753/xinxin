# CASE-0068｜图符与图例记录数据字典

[基础数据集](./基础数据集.csv)有 **3 行、11 列**。每行对应一个可辨图符换算规则或状态图例。数据来自用户附图 `ISOTYPE-FIG-04`。当历史统计原表可得时，应另作数值表并记录来源。

| 字段 | 定义 |
|---|---|
| `record_id` | 案例内唯一编号 |
| `metric` | 指标或图例所指状态 |
| `symbol_scope` | 一个规则覆盖的图符单元 |
| `symbol_unit` | 一个图符单元对应的数值，状态图例可留空 |
| `unit` | 对应计量单位，历史重量按原图保留 |
| `denominator` | 比例所用分母，计数无需分母时留空 |
| `period` | 图版所示的比较时段 |
| `encoding_or_applicability` | 颜色、形态、状态或规则适用栏目 |
| `legend_position` | 图例在页面的大致位置 |
| `source_id` | 对话附图标识 |
| `evidence` | E1 表示图面文字及可见编码 |

本表可复核单位和状态标识。部分图符的比例及各行统计值以进一步核验的结果为准。
