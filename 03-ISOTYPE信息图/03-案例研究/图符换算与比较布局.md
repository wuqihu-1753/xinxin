# 图符换算与比较布局

这份方法回写来自 CASE-0065 至 CASE-0070 的用户图面观察、可查书目与馆藏记录。用于补充专项关于单位图符、视觉编码与设计实践的规则。

## A｜确定图符在什么范围内计数

先定统计对象、时期和比较粒度，再定符号单位的适用范围。全图可以共用一个单位，也可以按列、整行或图符组公布不同单位。百分比要给出分母，历史重量要保留原单位与可核实的制式。图例宜放在对应系列附近。

- [CASE-0065 美国职业构成变化](./CASE-0065-美国职业构成变化/分析.md) 以当年全部有职业劳动者为分母。
- [CASE-0066 四国就业与失业对照](./CASE-0066-四国就业与失业对照/分析.md) 在同一页面同时用到就业人数、女性劳动力占比与失业人数。
- [CASE-0067 英国1945年食品需求](./CASE-0067-英国1945年食品需求/分析.md) 以满行图符为单位，标准单枚与余量的换算需进一步查证。

## B｜分开标注数量、类别、状态和余量

同一指标的完整图符保持尺寸，重复次数承担数量编码。用形状识别对象，用颜色或填充区分类别与状态。若部分图符承担余量，需要说明换算比例与舍入规则。[CASE-0067 英国1945年食品需求](./CASE-0067-英国1945年食品需求/分析.md) 的**完整蓝色描边**对应缺口状态，[CASE-0069 英国与美国的人口和牲畜](./CASE-0069-英国与美国的人口和牲畜/分析.md) 的**裁切牲畜图符**需要核对部分单位的读法。

若一枚图符代表 100 人，完整 3 枚另加按图例定义的半枚，表达 350 人。若作品采用四舍五入，可保留原数值并标示图符近似值。图面样式或裁切比例不明时先保留图例证据。

## C｜用布局确定比较任务

| 阅读任务 | 适合的排列 | 对应案例 |
|---|---|---|
| 查看行业构成如何变化 | 各年使用一致的分母定义和对齐基线，横读构成、纵读变化 | [CASE-0065 美国职业构成变化](./CASE-0065-美国职业构成变化/分析.md) |
| 同页查阅多个指标 | 分列标出图符单位，跨组比较优先在同一列进行 | [CASE-0066 四国就业与失业对照](./CASE-0066-四国就业与失业对照/分析.md) |
| 看同年的数量与产量 | 并列呈现指标带，统一年份，再按各自单位读数 | [CASE-0068 英格兰家庭与工厂织造](./CASE-0068-英格兰家庭与工厂织造/分析.md) |
| 比较基数悬殊的对象 | 用近似相当的基数分块，保留原始总量和近似说明 | [CASE-0069 英国与美国的人口和牲畜](./CASE-0069-英国与美国的人口和牲畜/分析.md) |
| 比较同一事件的两方 | 用清晰的列头、对齐和颜色标出双方，写明可比较的对象 | [CASE-0070 古代与中世纪军队规模](./CASE-0070-古代与中世纪军队规模/分析.md) |

## D｜分别核验三类证据

1. **作品出处**。记录图版题名、作者或机构、出版物、年代、页码与可查来源。
2. **图符换算**。记录单位作用于每枚、整行还是组，注明分母、栏目、状态、余量规则及图例位置。
3. **原始数据**。保留独立的原始统计表、口径与时间信息。作品出处与图例核验后，仍需独立追溯数值来源。

设计实践可按「明确比较问题 → 核对基础数据 → 选择图符和计量范围 → 安排分组与基线 → 检查图例与余量 → 测试读者读数」执行。读数测试重点检查换列时的单位切换、完整空心与裁切图符的区分，以及读者能否解释百分比的分母。
