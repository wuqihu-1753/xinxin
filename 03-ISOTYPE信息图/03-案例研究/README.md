# 03｜ISOTYPE专项案例研究

按[参考仓库规范](https://github.com/fengbaifan/Infographic-Style-Repository/tree/main/03-ISOTYPE信息图/03-案例研究)记录历史原作、方法前身、当代方法应用与视觉借鉴。历史候选及反例见[既有方法与证据索引](./既有方法与证据索引.md)。

新案例实行一案一档，按需附`分析.md`、`基础数据集.csv`、`数据字典.md`与`原图来源.md`。只在授权明确时公开原图；已有02 CASE链接复用，不重编号或复刻原图。

## 六个专项案例

本批核对了六张图上的图例。两件历史 ISOTYPE 作品可核对出版图版，一件维也纳图像统计法前身作品可核对馆藏图版。另有一件可查书目的美国象形统计实践，两件图面换算可读、原作出处待核的样例。完整原始统计表仍待逐件核验。

| 案例 | 归档定位 | 图符换算要点 |
|---|---|---|
| [CASE-0065 美国职业构成变化](./CASE-0065-美国职业构成变化/README.md) | 美国象形统计实践 | 1 枚完整人形 = 当年全部有职业劳动者的 10% |
| [CASE-0066 四国就业与失业对照](./CASE-0066-四国就业与失业对照/README.md) | ISOTYPE 式多指标矩阵，出处待核 | 就业 300 万人／枚，女性占比 10 个百分点／枚，失业 150 万人／枚 |
| [CASE-0067 英国1945年食品需求](./CASE-0067-英国1945年食品需求/README.md) | 历史象形统计图，出处待核 | 1 整行图符 = 100 万 tons。绿实心国内生产，蓝实心进口，蓝描边缺口 |
| [CASE-0068 英格兰家庭与工厂织造](./CASE-0068-英格兰家庭与工厂织造/README.md) | 历史 ISOTYPE，出版图版已核 | 蓝色每枚 5,000 万磅产量。黑、红完整人形每枚各代表 1 万名相应织工 |
| [CASE-0069 英国与美国的人口和牲畜](./CASE-0069-英国与美国的人口和牲畜/README.md) | 历史 ISOTYPE，出版图版已核 | 各类完整图符每枚分别代表 500 万人口、牛、猪或羊 |
| [CASE-0070 古代与中世纪军队规模](./CASE-0070-古代与中世纪军队规模/README.md) | 维也纳图像统计法前身，馆藏图版已核 | 每枚完整人物图符代表 1 万人 |

专项案例沿用全库连续 CASE 编号，CASE-0065 至 CASE-0070 在本目录归档。
