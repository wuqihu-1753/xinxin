## 学习与研究路径

**数据组织逻辑（01）→表现形式与案例（02）→跨类型图像语言（03）→统计图形机制（04）→视觉知觉组织（05）→主题应用和实施（06）。**

- ISOTYPE属于跨类型图像统计与信息转译方法，**不再作为02的第18个表现形式编号**；原18号研究正文归入03。
- RAWGraphs的32个图表标识依赖文档中所记录的**具体源码快照**，不代表永久固定的官方图表总数。
- Gestalt的12或13项不是学界公认唯一法则数；本库为保留Connectedness与Uniform Connectedness的独立研究，使用13项。
- 已有37个CASE是案例研究记录，不等于37份已复核基础数据。只有表头的CSV仍为0条真实观察记录。
- 未获原作公开授权不复制第三方整图；视觉编码论断与统计事实须区分证据层级。
