# 视觉编码与设计评价清单

> 课件范围：PDF 第40–57页、62–72页。以下**课件提纲**与**实施化建议**分开标注。

## 一｜课件提出的选择原则（p40）
1. 可视化形式要匹配信息内容，关注叙事性。
2. 可视化机制要匹配读者背景，兼顾趣味性。
3. 面向专业读者可以采用更专业的图形语言。

**研究补充**：形式首先受数据的可比性和量纲约束，不以艺术化取代可读性。

## 二｜七组视觉评估轴（p48–53，课件有相对关系）
- 抽象（概念化） ↔ 模拟（具象）
- 实用（朴素） ↔ 修饰（花哨）
- 致密 ↔ 稀疏
- 多维 ↔ 单维
- 创新（独特性） ↔ 通用（普遍性）
- 简洁（清晰） ↔ 冗余（深度）
- 课件 p45–46 另示测试轮盘，并将工程师侧重理性实用、设计师侧重趣味情感作为对照。这是**观察维度不是评分的客观测量结果**。

建议每轴采用 1–5 **研究者主观编码**，并写出图中的证据；不要把雷达图数值当未经验证的心理测量。

## 三｜数据/油墨比与图表垃圾（p54–57）
课件原意：重视有用数据对视觉资源的占比，避免装饰妨碍准确传递。
- 数据/油墨比（Data-Ink Ratio）定义：**用于表示数据的墨量 / 整幅统计图的总墨量**，这里的“墨”是概念性视觉标记，不是直接计数所有彩色像素。
- 对图例、单位、轴、必要解释不能机械删减：它们虽然不直接表示具体数据值，却可能是**理解与验证必需的语义信息**。
- 图表垃圾（chartjunk）：无必要且干扰/扭曲数据的修饰，不能等同“所有装饰都错误”。

术语外部校核：[NASA 概述 Tufte 信息显示原则](https://www.nas.nasa.gov/assets/nas/pdf/techreports/1994/nas-94-002.pdf)；[乔治梅森大学数字历史讲义](https://chnm.gmu.edu/digitalhistory/links/cached/chapter4/4_13b_tufte.htm)。

## 四｜可审计的质量检查项（实施化）
| 检查维度 | 问题 | 失败迹象 |
|---|---|---|
| 数据准确 | 数值、单位、时间窗、分母是否可核实？ | 百分比无分母、缺失当零 |
| 结构契合 | 图形和数据关系是否匹配？ | 将地图视作树、时间轴等距伪装成真实时间 |
| 视觉编码 | 长度/面积/色彩/符号有固定语义吗？ | 图标随意变大或半径取代面积 |
| 叙事可查 | 关键结论是否有图中证据？ | 只有情绪标题无证据 |
| 可读性 | 主次、字级、对比和图例合理吗？ | 标签过密、对比不足 |
| 读者契合 | 是否在不损害信息深度的前提下适配知识？ | 误以为读者看不懂而删除有用信息 |
| 版权与出处 | 原图是否授权、信息能否回溯？ | 作者/发布年份臆测 |

## 五｜课件还提出的风险（p44、p47、p66–71）
- 复杂不是原罪；真正风险是数据没看懂、结构未梳理。
- “信息太多”先检查内容整合，而不等于将数据一概删掉。
- 不应为装饰而稀释分析深度：先考虑数据组织，再选表现风格。
- 避免把假定的读者智力作为简化信息的依据。

## 六｜第二讲补充：可验证的视觉准确性优先（v0.3）

《第二讲(2).pdf》p9、p11–13 提出减轻读者搜索、记忆、心理排序和比较负担；[CASE-0027](../02-信息图形类型案例/案例库/CASE-0027-西班牙地区失业率图表改版.md)比较分散地名地图与预排序条形图，体现了让图形完成排序的思路。

p32–33 气泡图涉及面积编码，正确关系为 `圆面积∝数值→半径∝√数值`。不能把“半径直接与数值成比例”作为避免误导的手段。详见[视觉感知与气泡面积](../04-数据类型与基础统计图表/10-视觉感知与气泡面积.md)；Cleveland & McGill 论文见[1984 原文](https://www.tandfonline.com/doi/abs/10.1080/01621459.1984.10478080)。

图表默认以位置/长度进行精确比较；若使用面积、角度、照片或装饰，需要提供足够的数字与图例作为辅助。课堂的柱形宽间距、最多项目/折线条数只是经验值，不能机械当作规范。
