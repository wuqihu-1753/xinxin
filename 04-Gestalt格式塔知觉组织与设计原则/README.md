## 使用与更新规范
1. 每条规则按 **A定义/B视觉线索/C信息架构/D叙事/E案例/F实践/G来源与边界** 维护。
2. 对“研究支持的现象”“设计应用推导”“未经测试的效果主张”分别标明证据等级。
3. 与 [02 CASE案例](../02-信息图形类型案例/00-案例索引.md) 交叉关联，不复制原作整图；示意图全部原创标示。
4. Gestalt 条件依赖、可能冲突，**不要把‘邻近永远压倒相似’写成普遍定律**。
5. 信息图审查先看数据与图例的真实性，再看布局的知觉组织；不为视觉简洁删除必要事实。
