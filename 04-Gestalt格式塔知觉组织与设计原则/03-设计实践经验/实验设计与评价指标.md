# Gestalt 在信息图形中的实验设计与评价指标

## 一｜实验流程
1. 明确具体任务：如找出某城市对应的GDP数值，而非抽象地问“哪个设计好看”。
2. 准备基线版本A与变量修改版本B；保持同一基础数据、图形尺寸与单位。
3. 选择要研究的主要线索：距离、颜色、边界、连接或动态同步。
4. 设定样本和记录方式；不预先宣称某组的优越性或固定样本量。
5. 每个受试者在可控条件下完成任务，记录正确率、完成时间、错误归属、主观理解和反馈。
6. 对结果做必要的描述统计；有比较推断时再考虑适用的统计检验和效应大小。
7. 报告所有局限，包括色觉差异、阅读经验、屏幕、样本来源和顺序练习效应。

## 二｜可用指标
| 指标 | 如何记录 | 常见误区 |
|---|---|---|
| 分组正确率 | 实际正确分组次数/有效任务次数 | 没有预定义正确答案或语义关系 |
| 标签配对正确率 | 把标签和数据对象正确连起来的比例 | 图形类型或数值本身被同时修改 |
| 完成时间 | 从任务开始到确认答案，单位毫秒或秒 | 把回答速度等同理解正确 |
| 错误类型 | 跨行错配、颜色误判、连线误读、轴读错 | 只报告总错率而不解释机制 |
| 信心/负担 | 明确定义问卷项或简短后测 | 主观分数不等于准确性 |
| 无障碍阅读 | 缩放、灰阶/色盲模拟、减少动态等 | 将软件模拟当作真实用户实验 |

## 三｜记录的变量
受众、样本量、任务材料、数据版本、呈现媒介、距离和字号、实际图例、A/B设计差异、顺序随机化和排除规则；变化多个变量时需注明“组合干预”而非单规则因果。

## 四｜反向更新
只有通过测试才将“经验”升级为“适用条件下的观察”；未测试保持建议性质。将结果链接到具体CASE和对应规则。参考[冲突矩阵](../14-规则组合冲突与优先关系.md)。
