# 10｜面向设计研究的可视化风格卡与交付规范

> 本篇为 xinxin 使用 RAWGraphs 的**设计方法提案（DESIGN）**，不是其源码自带的可执行模板或 CSS 主题。实际可配置控件须依 [ChartOptions](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/components/ChartOptions/ChartOptions.js) 与各图的visualOptions决定。

## A. 图形风格卡通用结构

| 栏位 | 应记录的内容 |
|---|---|
| 风格ID | RAW-STYLE-XX |
| 图形注册ID | 与 [内置图表](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/charts.js) 一致 |
| 关联数据结构 | 编年/层级/编目/字母索引/地理或其他流动/网络 |
| 视觉目的 | 比较、趋势、构成、结构、关系、密度、检索 |
| 统计约束 | 输入字段、统计聚合、单位、分母、尺度 |
| 视觉语言 | 点线面、色彩尺度、主题字形、主次与图例 |
| 排版角色 | 主图、辅助证据、内嵌图表或配图 |
| 图形可编辑性 | 导出SVG，保存 .rawgraphs 与源数据 |
| 准确性核验 | 位置/长度/面积/带宽是否对应数据 |
| 来源/许可 | 原始数据和工具版本分别记录 |

## B. 六张建议采用的风格卡（非程序内置）

### RAW-STYLE-01｜极简数据比较
- 适用：barchart、slopechart、beeswarm、boxplot；
- 形式：无多余装饰，优先位置/长度，稳定纵向栅格和可读单位；
- 用户任务：快速找最大最小、异常值、差异；
- 排版：左侧/顶部标题，关键数字靠近图形，不将柱长重画为品牌标志。

### RAW-STYLE-02｜有机层级面积
- 适用：circlepacking、sunburst、treemap、voronoitreemap；
- 形式：统一圆/矩形的比例映射，分支同色系，突出父子包围；
- 用户任务：看整体组成、深层归属或叶节点对比；
- 风险：不要为圆形美感创建错误父子树或混用半径与面积。

### RAW-STYLE-03｜曲线关系叙事
- 适用：sankeydiagram、alluvialdiagram、chorddiagram、arcdiagram；
- 形式：流向和类别分组成为主视觉，色彩用于类别，流宽仅在有量化时编码；
- 用户任务：解释源头、去向、连接密度和主要路径；
- 风险：需控制线交叉、拥挤与虚假流量。

### RAW-STYLE-04｜时间层叠编年
- 适用：linechart、ganttChart、streamgraph、calendarHeatmap、bumpchart；
- 形式：明确真实时间刻度、阶段色带与关键事件注释；
- 用户任务：看时间变化、持续区间和转折；
- 风险：避免仅凭曲线形状夸大绝对变化值。

### RAW-STYLE-05｜高密度知识索引
- 适用：matrixplot、parallelcoordinates、treemap；
- 形式：字段一致、行列可扫描、同一指标独立色标，必要时加小倍数；
- 用户任务：查条目和比较多维属性；
- 风险：图例与标签密度过高影响识别，不把类别数字编码当数值。

### RAW-STYLE-06｜编辑信息图形混合
- 适用：先分别导出 bar/line/matrix/Sankey等多个SVG，再在外部版面组合；
- 形式：完整主标题、导语、图表证据、文化/解剖/人物/专题插画与结论；
- 用户任务：建立多入口的“背景→指标→解释→行动”叙事；
- 参考：[CASE-0032 马年专题](../../02-信息图形类型案例/案例库/CASE-0032-马年生肖专题混合信息图.md)和[CASE-0033 鸡与蛋生命周期](../../02-信息图形类型案例/案例库/CASE-0033-鸡与蛋生命周期混合信息图.md)的视觉构图方法；
- 边界：RAWGraphs **不会凭一个表格自动生成整张报纸式主题插画信息图**，编辑组合仍需人工设计。

## C. 以 A–E 设计语言评价一张风格卡

A **数据逻辑**：读者能辨别结构主体吗？

B **统计逻辑**：字段、聚合、分母、轴和量纲可以核实吗？

C **视觉编码**：颜色、线宽、面积、符号和图例是否具有稳定语义？

D **信息架构**：能先读总体再读细项吗，是否允许按需检索？

E **视觉叙事**：标题问题是否被图中事实支持，插画有没有掩盖事实？

## D. 项目交付结构建议（样式与数据同时保存）

```text
可视化项目（设计者本地目录，不是要求新建xinxin文件夹）/
  source.csv / source.json
  README-data.md      # 字段、口径、来源
  draft.rawgraphs     # 图表可复原状态
  chart-original.svg  # 原始准确图形
  infographic-edit.svg
  preview.png
  CHANGELOG-design.md # 后期配色、文字、装饰变更
```

通过 RAWGraphs 的 SVG 和 .rawgraphs 两种输出，可以实现“**数值层可回溯、视觉层可再设计**”，这是其与信息图形编辑工作流程最值得吸收的特点。注意 app 里仅提供 SVG/JPG/PNG/项目导出，**不提供原生 AI/PSD/INDD 设计源文件导出接口**。
