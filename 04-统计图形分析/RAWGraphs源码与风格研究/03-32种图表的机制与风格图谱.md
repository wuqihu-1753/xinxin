# 03｜32种内置图表：数据机制与视觉风格图谱

> **严格源码事实**：本表的32个注册标识来自 [src/charts.js](https://github.com/rawgraphs/rawgraphs-app/blob/48c3b2ee9ff412721a2c99c7bed38e734b3fa534/src/charts.js)，统计于 master 提交 `48c3b2ee9ff412721a2c99c7bed38e734b3fa534`。其中 31 来自 `@rawgraphs/rawgraphs-charts`，`calendarHeatmap` 来自单独的 `@rawgraphs/rawgraphs-calendar-heatmap`。
>
> **DESIGN 推断**：分组、中文称呼、适用场景是本知识库为教学/设计研究整理的**功能分类**，并非 `metadata.categories` 官方值，也不能代替每个 chart 包里 `dimensions` 的精确约束。详细算法应继续检查 [rawgraphs-charts](https://github.com/rawgraphs/rawgraphs-charts)。

## A. 32图注册标识（精确名称）

| 研究分组（非官方分类） | 注册的图表标识（与源代码完全对应） | 核心视觉编码研究 |
|---|---|---|
| 类别比较/排序（6） | `barchart`、`barchartmultiset`、`barchartstacked`、`bumpchart`、`slopechart`、`radarchart` | 共同基线、长度、数值排序、名次路径、多指标放射比较 |
| 时间/历时（5） | `linechart`、`streamgraph`、`horizongraph`、`ganttChart`、`calendarHeatmap` | 位置、曲线、带状面积、时间跨度、日期格子 |
| 分布/数值空间（8） | `boxplot`、`violinplot`、`beeswarm`、`bubblechart`、`hexagonalBinning`、`contourPlot`、`parallelcoordinates`、`convexHull` | 分布密度、点位置、尺度/面积、聚合网格、多维线、外边界 |
| 层级/总体—部分（6） | `treemap`、`voronoitreemap`、`sunburst`、`circlepacking`、`dendrogram`、`circularDendrogram` | 矩形面积、Voronoi区域、径向分层、圆包围、树枝路径 |
| 关系网络/流量（5） | `alluvialdiagram`、`sankeydiagram`、`chorddiagram`、`arcdiagram`、`matrixplot` | 流带宽度、节点连接、弦关系、弧线、邻接矩阵色格 |
| 多边形空间剖分（1） | `voronoidiagram` | 最近邻生成的多边形单元；**未必是地理数据** |
| 构成比较（1） | `piechart` | 扇区角度/面积，注意总量和分母 |

**校验**：6 + 5 + 8 + 6 + 5 + 1 + 1 = **32**。同一个图可以同时含有时间、类别、层级和空间结构，本表按教学使用场景**选一个主位置**，并不强制互斥。

## B. 重点图的研究速查

| 图形 | 最小数据关系（设计推荐，并非包内正式schema） | 识别视觉语法 | 设计风险 |
|---|---|---|---|
| Beeswarm plot 蜂群 | `item_id, numeric_value[, category]` | 同一数值轴的非遮挡离散点簇 | 横向位移通常是避让，不是第二个可读数值轴 |
| Circle Packing 圆圈打包 | `node, parent, value` | 同心/包围圆及数量面积 | 半径需以面积校准，嵌套层次不等于空间邻近 |
| Treemap 矩形树图 | `node,parent,size` | 递归分割的矩形面积 | 面积权重需可加总；不能凭父节点文字断言权重 |
| Sunburst 旭日图 | `node,parent,value` | 以径向深度编码层级 | 半径/角度的读取复杂，整体—部分需解释 |
| Chord Diagram 弦图 | `source,target,weight` | 环形类别＋弦带流量 | 类别排序严重影响阅读，弦带数量过多导致遮挡 |
| Sankey diagram 桑基图 | `source,target,flow` | 连续节点与带宽表示流量 | 总量守恒需数据支持，不是所有有向连接都能做桑基 |
| Alluvial Diagram 河流图 | `stage,category,flow_id/weight` | 不同阶段的类别流带 | 纵向类别排序和跨层权重须记录 |
| Matrix Plot 矩阵 | `row,column,value` | 行列格子的颜色/明度 | 分类矩阵不一定有连续值或完整邻接关系 |
| Gantt chart 甘特 | `task,start,end[,group]` | 任务区间条，时间共轴 | 不等时间距不能假装等长 |
| Streamgraph 流图 | `time,category,value` | 随时间变化的层叠流带 | 无固定零基线时不易精确比中间层 |
| Horizon Graph 地平线 | `time,value[,group]` | 折叠/分层色带表示振幅 | 需要读者理解基准和分段的图例 |
| Bump chart 排名变化 | `time,entity,rank` | 多条名次线的上下交错 | 排名序数不能与真实数值差距混为一谈 |
| Parallel Coordinates 平行坐标 | `id,metric1...metricN` | 每轴一维，折线连接指标 | 各轴归一化及类别/数值混用需谨慎 |
| Bubble Chart 气泡 | `x,y,size[,category]` | 点位置＋圆面积 | 若面积表达v，半径应 `r∝√v`，不是 `r∝v` |
| Voronoi Diagram 泰森多边形 | `x,y[,category]` | 根据样本点分割空间区域 | 视觉几何不等于真实行政边界 |

## D. 风格与数据逻辑不能混淆（核心结论）

- 线性/径向/平铺是**几何布局风格**：如 dendrogram 与 circularDendrogram 都可能编码树结构。
- 长度、面积、颜色、弧宽是**定量或分类视觉编码**：不能只看图形“华丽/简约”判断统计真实性。
- 圆圈打包与圆形气泡都用圆，但前者强调**层级包含**，后者常强调**多维数值比较**。
- 桑基图与一般流程箭头都具有连接，只有流量值/带宽定义支持时才认定具有定量流动含义。
- 矩阵图与字母表型：矩阵按行列索引，是否属于字母表数据逻辑要看其索引键是否真的由A–Z排序决定。
