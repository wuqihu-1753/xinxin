# 阶段05｜叙事框架搭建：把字段组合为有主题的信息单元

> 与阶段04不同：**基础数据表保存原子变量；叙事框架根据明确的问题选择、关联或变换若干列，形成“有意义的句子和图形模块”**。叙事不能靠图形拼贴自动产生。

## 1. 字段→命题→图形，不是字段→装饰

| 组合字段（基础表中分列存放） | 能回答的实际问题 | 叙事模块和图形可能性 | 需要检查 |
|---|---|---|---|
| `名称 + 纬度 + 经度` | 这些地点在哪里？ | 地图点位/地点信息卡 | 坐标系、精度、许可与敏感地点 |
| `地区名称 + GDP数值 + 年份 + 单位` | 哪些地区在同一年GDP较高？ | 地区排序条形 + 说明（可辅地图） | 同币种、同年份、同价格口径；不能先编造GDP值 |
| `事件名称 + 日期 + 文字说明` | 发生了哪些重要事件？ | 时间轴 + 时间事件说明卡 | 事件选择标准，日期真实性 |
| `类别 + 人数 + 总人数` | 各类别占比多少？ | 比例条/ISOTYPE（条件满足时） | 分母、重复人形单位、舍入方式 |
| `关键词 + 词频 + 文献范围` | 哪些词出现最多？ | 统计词云/排序条形 | 分词、停用词、样本范围 |
| `人物/物品 + 单张图片URI + 文本描述` | 不同类别有何视觉特征？ | 图片式图鉴/文字列表型 | 图片来源/版权、样本代表性 |
| `source + target + weight` | 哪些实体存在关系或流动？ | 关系图/桑基图（仅有流量意义时） | 有向性、权重单位、是否守恒 |

**这些只是字段组合的教学结构示例，不代表当前选题已获得任何实际地理或GDP数据。**

## 2. 叙事结构的三层

- **总问题**：此份作品的核心命题是什么？有什么重要发现可以被证实？
- **模块问题**：每个统计图、地图、图片或文本列表分别回答哪个子问题？连接顺序为何？
- **读者路径**：先看什么、如何比较、解释如何跟随证据、最后学到什么？允许单线、循环和多入口式，但需自洽。

叙事框架建议使用：[字段组合到模块映射表](字段组合与叙事模块映射模板.md)、[故事板/信息架构卡](叙事结构与分镜模板.md)。

## 4. 完成门槛

每个模块都应有**读者问题 + 来源字段 + 预期图形 + 统计计算（若有） + 一句可证的核心陈述 + 可能的误读**，并声明是否属于主线、旁支或纯视觉锚点。没有数据支持的结论必须标“待核”，不能写为确定事实。
