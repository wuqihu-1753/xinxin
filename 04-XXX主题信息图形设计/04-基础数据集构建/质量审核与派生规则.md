# 数据质量核查与派生表规则

## 基础数据表的检查清单
- [ ] **主键**：每条记录有稳定 `record_id`；若一对象多时期，明确 `entity_id + year` 的复合唯一键。
- [ ] **字段原子化**：任何单元格只有一个字段值；不存在把 `GPS = "纬度,经度"` 当作不可拆数字；经纬度分别存列。
- [ ] **缺失值**：缺失与数值0不同；空、NA、不可用等统一编码并记录。
- [ ] **数字单位**：金额币种、价格年度、百分比/百分点、人数/每万人比率不混同。
- [ ] **时间范围**：日期标准化、时区及调查时点一致；不等间隔仍要保留真实时间。
- [ ] **文本编码**：词频数据需说明清洗、分词、去停用词、人工标注规则。
- [ ] **图像与版权**：一个图像URI对应一项素材；来源/作者/用途/许可单独登记。
- [ ] **来源和变换**：每个字段可回溯 SRC-编号，统计和清洗规则可复算。
- [ ] **异常与重复**：记录移除/合并/修正的原因，不能因“图面更整齐”随意删异常值。

## 派生表怎么做
派生表应记录：`dataset_version, input_file, selected_fields, filter, group_by, aggregation, formula, output_file, review_status`。例：GDP总额和人均GDP需要不同分母与口径，不能用字段别名混用。生成人均值之前必须有合理人口数据及匹配年份。

**本模板不含真实XXX项目记录**；待选题确定后填入第03阶段的可靠数据，数据计算在正式可视化前另行验证。
